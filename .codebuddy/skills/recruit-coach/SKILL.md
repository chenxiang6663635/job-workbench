# 秋招岗位评估与材料纪律

## 核心原则

**判断由 AI 做，脚本只做 IO 与校验。** 评分不是 Python 算出来的，是你读 JD 原文与 `CODEBUDDY.md` 后填进解析卡的；`tools/jd_score.py` 只校验加总自洽并套阈值。改评分标准不用改代码，只改本文件或 `config/`。

**唯一事实源是 `00_事实库/`。** 简历动词、行为故事、经历匹配打分都必须回查事实卡，不得以解析卡概述或 `CODEBUDDY.md` 摘要为准。

## 流程：先过滤，再打分

Eligibility Gate 不通过 → **不打分、不写材料、不调 `/apply`**，直接输出「不建议投递 + 原因」并终止。

判定顺序：学历 → 专业 → 届数 → 英语 → 城市。事实取自 `CODEBUDDY.md` 第三节。

**任一字段为 `[待填]` 时按 fail 处理**，输出中显式提示「请补齐 CODEBUDDY.md 中的 X 字段」。禁止猜测，禁止按「可能满足」放行。

城市为 pass/fail，不参与加权。工作形态问题（长期驻场、倒班、长期出差）不在此判定，归入「培养与稳定性」扣分。

## 评分：四维度

| 维度 | 分值 | 判据 |
|---|---:|---|
| 技术匹配 | 30 | Primary 命中 3 分/项，Secondary 1.5 分/项；Weak 登记不扣分但触发风险提示 |
| 经历匹配 | 25 | 三条经验资产（项目二、项目一、某商业综合体实习）逐条比对 JD 职责。对上核心职责 8–10 分，侧面支撑 3–5 分，无关 0 分 |
| 方向契合 | 30 | 按 `config/direction_*.md` 锚点表取值 |
| 培养与稳定性 | 15 | 见下表 |

**培养与稳定性（15）**

| 分值 | 判据 |
|---|---|
| 13–15 | 明确校招培养体系（导师制 / 轮岗 / 培训），岗位为技术核心岗，无强制长期驻场或倒班 |
| 9–12 | 校招岗但培养体系未明示，岗位偏技术，工作地可接受 |
| 5–8 | 培养信息缺失；岗位偏运维或现场执行；或需长期出差 |
| 0–4 | 劳务派遣 / 外包、非技术岗、强制倒班或驻场不可接受 |

本维度取代原框架的「文化契合」。校招 JD 里的文化表述多为套话，从文本判断可靠度低；而是否有培养体系、是否核心岗、工作形态是否可持续，既可从文本判断，也对决策影响更大。

## 阈值与动作

| 总分 | 档位 | 动作 |
|---|---|---|
| 75–100 | 强烈建议投 | 立即 `/apply` |
| 60–74 | 建议投 | 进入 `/apply` |
| 45–59 | 斟酌 | 先看缺口能否一周内补，再决定 |
| 30–44 | 大概率跳过 | 除非有内推或岗位调整等额外信息 |
| 0–29 | 不投 | 终止 |

## 方向配置

按 `--direction` 加载 `config/direction_datacenter.md` 或 `config/direction_hvac.md`。两个方向共用同一权重与流程，差异只在关键词词典与方向锚点。

**不建第三个配置文件。** 遇到两个方向之外的岗位（建筑节能咨询、热管理硬件等），回退数据中心配置，并在解析卡末尾追加一行：

```
⚠️ 该岗位不属于两个预设方向，评分基于数据中心配置计算，结论仅供参考。
```

## 七条诚实红线

完整表述见 `CODEBUDDY.md` 第五节。要点：

不认领 CNN 前端；X% 表述为「研究案例显示」；不包装数据中心交付经验；项目一只讲已验证结论与探索候选；项目二只说仿真与单一案例；动词经得起 5–10 分钟追问；知识缺口用诚实桥梁回答而非编造。

**桥梁话术同样受此约束**：只能指向真实可迁移能力（如「项目二的工况运行经验可迁移到此处」），不得生成听起来像亲身经历的表述。

## 简历改写边界

三套简历 = 1 Master + 2 派生，**只改四处**：求职方向、Profile、技能顺序、项目表述。项目事实一律不动。

生成 PDF 后必须过 ATS 校验（页数 = 1、可提取文本、关键事实存在性），任一项不通过则中止归档。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 跳过 Eligibility Gate 直接打分 | 浪费时间在不合格岗位 | 先过滤，不过则终止 |
| 用解析卡概述当事实依据 | 简历出现经不起追问的动词 | 回查 `00_事实库/` |
| 硬门槛字段缺失时猜「应该满足」 | 投递后被学历或届数卡掉 | 按 fail 处理并提示补齐 |
| 命中 Weak 项后生成听起来像经历的话术 | 面试露馅 | 只说可迁移能力，明确标注是知识性了解 |
| 自动执行 `git commit` | 含隐私的仓库出现非预期提交 | 生成提交信息交用户确认 |
| 给第三类岗位临时造权重 | 评分体系失真 | 回退数据中心配置并标注 |
