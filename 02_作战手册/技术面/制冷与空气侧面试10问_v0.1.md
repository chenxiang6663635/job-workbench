# 制冷与空气侧面试10问

> 可直接作答案。对应速查卡：制冷循环与COP、空气处理与焓湿图。

**1. 为什么压缩机不"制造冷量"？**
压缩机消耗电功，作用是把低压蒸气压缩升压升温，维持蒸发器低压与冷凝器高压之间的循环；真正吸热产生制冷效果的是蒸发器。热量靠制冷剂从低温侧搬到高温侧。

**2. 蒸发温度过低为什么会降 COP？**
蒸发温度↓ → 蒸发压力↓ → 压缩比增大 → 压缩机单位冷量耗功↑、制冷量与输气效率通常↓ → COP↓。但蒸发温度须低于被冷却对象才能吸热，故应在满足换热前提下尽量提高蒸发温度。

**3. 冷凝温度过高为什么会降 COP？常见原因？**
冷凝温度↑ → 冷凝压力↑ → 排气背压与压缩功↑、制冷量可能↓ → COP↓。原因：室外气温高、冷却塔/冷却水泵异常、冷却水温度过高或流量不足、冷凝器脏堵结垢、系统有不凝性气体。

**4. 过热度和过冷度分别是什么，为什么要？**
过热度 = 吸气温度 − 吸气压力对应饱和蒸发温度，适度保证干蒸气防液击，过大说明供液不足。过冷度 = 冷凝压力对应饱和温度 − 液管温度，适度减少节流前闪发、提高有效液体比例；二者都须结合测点压力换算，非越大越好。

**5. 制冷和热泵用同一循环，区别在哪？**
核心循环相同（压缩/冷凝/节流/蒸发），区别在利用哪一侧：制冷用蒸发器从室内吸热；热泵用冷凝器向室内放热，经四通阀切换流向。热泵 COP_heating = COP_cooling + 1。

**6. 焓湿图是什么，和压焓图有何不同？**
焓湿图描述湿空气温度/含湿量/RH/露点/焓的关系，用于分析加热、冷却、除湿、加湿与混合；压焓图是制冷剂的循环图。前者管空气，后者管制冷剂，两者在空调盘管处相遇。

**7. 显热和潜热有什么区别？**
显热只改变温度不改含湿量（等湿冷热）；潜热与水蒸气相变有关（冷却除湿凝结水）。总冷负荷 = 显热 + 潜热；空调降温主要处理显热，除湿主要处理潜热。

**8. 等湿冷却和冷却除湿怎么区分？**
看盘管表面温度是否低于空气露点：高于露点只降温（含湿量不变）；低于露点则凝结排水（温湿同降）。夏季新风既要降温也要除湿，正是因为盘管须低于露点。

**9. 为什么"空调开得冷"不等于"除湿充分"？**
是否除湿看含湿量是否下降，而非干球温度。盘管温度高于露点时只等湿冷却；低于露点才冷却除湿。相对湿度下降也不等于除湿（等湿加热也降 RH 但含湿量不变）。

**10. 数据中心空气侧为什么以显热为主？**
服务器使空气升温但一般不明显释放水分，含湿量变化不大，故 CRAC/CRAH 主要搬显热。但机房仍须控湿度与露点：过干致静电，过湿致结露腐蚀，送风过低表面低于露点会结露。
