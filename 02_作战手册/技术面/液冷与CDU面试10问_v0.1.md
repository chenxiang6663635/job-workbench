# 液冷与CDU面试10问_v0.1

> 每题 80-150 字可直接作答，答案基于 `知识词典/液冷专题/` 速记。

1. **为什么高密度用液冷？** 高密度 AI 服务器 GPU/CPU 热流密度高，空气冷却需大流量大风压且易产生局部热点；液体体积热容远大于空气、可贴近热源取热，缩短传热路径、降低空气输送压力。

2. **液冷路线怎么选？** 按"热量在哪一层被液体接走"：强化空气→RDHx（机柜后门空气-水换热）→冷板式直接液冷（主线）→单相浸没→两相浸没（概念层）。冷板式最符合暖通背景。

3. **TCS 和 FWS 隔离价值？** 隔离有热工、水力和水质三方面价值：CDU 完成热量交换并建立独立 TCS 循环，同时把服务器侧与设施水侧的水质和化学控制域分开，使 IT 侧冷却液满足冷板、密封件、快接和材料兼容要求。

4. **CDU 是什么？** CDU 是连接服务器侧 TCS 与设施水 FWS 的换热、泵送、分配、控制、监测、保护一体化设备；通过液-液换热器把热量从 TCS 交给 FWS，两侧液体不混合，不是普通板式换热器。

5. **流量怎么算？** Q=ṁc_pΔT。200kW、ΔT=5/8/10K → 9.52/5.95/4.76 kg/s → 34.3/21.4/17.1 m³/h。温差大流量小，但受冷板最小流量、芯片温度和 CDU 工作范围约束。

6. **CDU 泵怎么控制？** 闭环：负荷增→回液温度/需求增→泵提频→流量压差增→温度反馈。恒压差控制简单但低负荷浪费泵耗；压差重置按最不利支路/阀位/负荷动态调整，与冷冻水泵控制同源。

7. **供液温度与露点？** 供液温度要同时满足芯片散热和环境露点约束：低于空气露点会在管路/接头/冷板附近结露，需控制露点安全裕量；在设备允许范围内尽量提高供液温度还可扩大自然冷却窗口。

8. **液冷可靠性核心？** 不是保证永不泄漏，而是异常后快速检测、限制故障域、维持必要冷却。泄漏用多源证据融合（漏液传感器/液位/静压/泵状态），响应按故障域分级：先局部隔离，必要时降载、迁移或安全停机。

9. **CDU N+1 等于无单点故障吗？** 不等于。CDU 数量 N+1 只是容量冗余，还要检查公共 TCS/FWS 主管、电源、控制器、通信、歧管和阀门是否有公共依赖，并验证备用泵/CDU 能自动切换、具备维护隔离能力。

10. **液冷设计与投运关键？** 设计先拿 IT 设备 thermal-fluid envelope：1MW IT、85% 覆盖率 → 850kW 液冷 + 150kW 空气侧；CDU 选型校核热容量/TCS 流量/扬程压差/冗余。投运五阶段：机械完整→液体准备→控制单机→系统平衡→带负荷与故障验证。
