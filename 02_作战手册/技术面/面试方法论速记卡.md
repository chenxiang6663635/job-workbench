# 面试方法论速记卡（行为面 vs 技术面 · 情景题 · 技术附件策略）

> 定位：面试应对策略总纲，不是题目库。题目库见本目录 `*面试10问`、`../行为面/行为面_印象最深项目问题.md`、`./实习技术面试压缩卡_某商业综合体.md`。
> 一句话区分：**行为面看"你是怎么做事的人"；技术面看"你能不能把专业问题做明白、讲明白、推理明白"。** 技术面试官也会问行为题，只是侧重点不同。

## 一、行为面：看工作方式 / 协作 / 稳定性 / 动机

**常见题**：遇到困难并解决的经历 / 与团队成员意见不一致 / 项目里失败过什么 / 最有压力的一次经历 / 为什么选这个岗位 / 为什么数据中心 / 为什么 HVAC / 最大优缺点 / 主动学习新东西的经历 / 多任务怎么排优先级。

**原则**：不能只讲观点，要讲真实事件。用 STAR + Reflection：
- S 情境 → T 任务 → A 行动 → R 结果 → **Reflection 复盘**（对研究生特别重要）

**现有行为故事库映射**：

| 故事 | 可回答 |
|---|---|
| 项目1：传感器缺失导致性能退化 | 发现问题、实验设计、科研困难 |
| 项目2：节能提高但 CO₂ 升高 | 权衡、反思、没有完美答案的问题 |
| 某商业综合体：图纸与现场施工差异 | 工程意识、现场沟通、学习能力 |
| 某商业综合体：风水管线/桥架空间协调 | 多专业协作、现场问题 |
| 项目2团队分工 | 团队合作、贡献边界 |

## 二、技术面：四类题

### 第一类：简历项目深挖（最该重视）
简历上每一个专业词都可能成为题目入口。例：为什么用 XGBoost？缺失怎么构造？为什么用 macro-F1？项目2新风阀开度怎么算？EnergyPlus 和 CFD 分别干什么？X% 的基准是什么？CNN 是不是你做的？
**准备法**：对简历每个专业词，准备"是什么 + 为什么 + 怎么验证"三问答案（见各项目 10 问压缩卡）。

### 第二类：专业基础
- HVAC 岗：蒸气压缩制冷循环 / COP / 焓湿图 / 显热潜热 / 冷冻水冷却水 / 水泵阀门变流量 / AHU/PAU/FCU / 冷却塔 / 离心机螺杆机 / Q=ṁc_pΔT
- 数据中心岗再加：CRAC/CRAH / 冷热通道 / PUE / N+1/2N / 冷站可靠性 / CDU/TCS/FWS / 液冷 / 故障诊断
**准备法**：见 `知识词典/` 4 子目录速记 + `核心题库/` 各专题 10 问。

### 第三类：情景题（考系统层级与因果链，不是背诵）
例：某个房间温度降不下来怎么排查？冷冻水 ΔT 很小可能是什么原因？GPU 高温但 CDU 供液正常怎么查？一台冷机故障后备用机怎么切换？
**排查框架**：按"数据 → 负荷 → 局部 → 系统 → 冷源"分层定位（沿用液冷可靠性故障树逻辑）。**某商业综合体真实案例可直接当技术案例**：900RT=3165kW、流量 545.2 m³/h、12/7℃，用 Q=ṁc_pΔT 核回来。

### 第四类：简单设计/计算题
例：200kW 负荷、ΔT=5K 要多少水流量？已知 IT 负荷和送回风温差要多少风量？2200RT 是多少 MW 冷量？
**准备法**：熟记 Q=ṁc_pΔT 速算（200kW/5K→9.52kg/s→34.3m³/h；850kW/8K→25.3kg/s→91m³/h；2200RT≈7.74MW）。

## 三、技术面要不要用 PPT/PDF？（关键策略）

**总原则**：招聘方没要求技术汇报，就不要主动放 10 分钟 PPT——秋招技术面本质是**简历驱动的问答面试**，主动放 PPT 可能打乱面试官节奏。

**三种情况**：
| 情况 | 做法 |
|---|---|
| A. 公司明确要求技术汇报/PPT 答辩 | 正式准备 PPT（会提前告知：5 分钟自我介绍+项目汇报 / 10 分钟技术 PPT / 课题答辩式） |
| B. 没有要求（默认） | 不开 PPT，正常问答；**准备 5–7 页"技术项目附件 PDF"放桌面备用** |
| C. 面试官主动问"能画一下系统吗/控制逻辑怎么走" | "我有一张项目系统图，如果方便我可以共享一下"——自然展示 |

**行为面**：不用 PPT，靠真实故事 + 清晰表达。

## 四、推荐方案：《技术项目附件 v1.0》（5 页 PDF）

> 不主动演示，随时可展示。价值：把三条技术主线视觉化——科研数据 → HVAC 控制 → 真实工程 → 冷却系统求职。

| 页 | 内容 | 要点 |
|---|---|---|
| P1 | 技术定位 | 暖通制冷/HVAC｜数据分析与控制｜数据中心冷却/热管理；3 关键词：HVAC 系统｜数据驱动控制｜工程现场（不要重做简历） |
| P2 | 项目1 | 只放一张逻辑图（完整数据→构造缺失→A0-A3→5 策略→XGBoost→macro-F1→部署约束）+ 右侧 3 个结果。不放几十张 SHAP 图 |
| P3 | 项目2 | 画 CNN(团队)→分区人数→新风需求★→DOAS 阀★→CCS/OBCS→E+/CFD→能耗/PPD/CO₂；旁注 -X%/DOAS-69.9%/PPD 14.3→7.2/CO₂≈1200ppm；明确标"本人贡献：控制策略、风量/阀门计算、工况运行、结果分析" |
| P4 | 某商业综合体 | 画 商业空间↑PAU/AHU/FCU↑冷冻水↑2×900RT+1×400RT↓冷却水↓5塔↓室外；旁注 2200RT≈7.7MW；下栏"我的现场工作" |
| P5 | 数据中心框架（仅 DC 岗） | IT 负荷↓CRAH/Cold Plate↓Air/TCS↓冷冻水/CDU↓FWS↓冷站↓冷却塔/Free Cooling；**必须写"系统学习/岗位准备，非本人已完成数据中心工程项目"** |

**技术能力地图（可替代 P5 或省略）**：HVAC 系统（制冷循环/冷冻水/冷却水/AHU-FCU）/ 数据控制（Python/XGBoost/控制逻辑/数据分析）/ 工程（冷站现场/风水系统/图纸核对/施工协调）。

**6 条铁律**：
1. 技术附件是"需要时展示的证据"，不是演讲稿——控制在 5 页左右。
2. 绝不做成 30 页硕士答辩 PPT（模型结构图/全部实验结果/每张 CFD 云图/所有施工照片）。
3. 备用展示 **PDF 优先**（打开稳定、字体不乱、动画不出错、在线共享方便）；公司要求 PPT 汇报时用 PPT；最佳状态 = 5 页 PPT 源文件 + 导出的 PDF。
4. **保密红线**：不要未确认就把完整施工图/完整设备表/施工单位内部文件/业主敏感信息/非公开设计资料放进附件。技术附件里**自己重画简化系统图**，不直接截整张工程图；现场照片只挑无敏感信息的一两张。
5. 数据中心框架页只在该岗位需要时放，HVAC 版不放。
6. 最后一页不写"谢谢"，放技术能力地图（5 页够时可省略）。

## 五、一句话总纲

> 行为面用真实故事（STAR+Reflection），技术面按"项目深挖→专业基础→情景题→计算题"四类准备；默认不开 PPT，备一份 5 页技术附件 PDF 随时可共享；涉及工程图纸/设备表一律自己重画简化图，守住保密红线。
