# 数据中心冷却容量匹配速查卡

> 配套正文：`数据中心冷却面试速记_v0.1.md` 四-J（机柜功率密度与"总量匹配 vs 局部匹配"）零节与四-B/四-C。
> 本卡为单页速查，细节与推导见主文档。

---

## 1. 一句话定义

冷却容量匹配：让冷却系统在实际运行条件下以合适方式移走热量，并把冷量准确送到需要的位置。既含"总冷量够不够"，也含"局部机柜是否真的得到足够风量和冷量"。

---

## 2. 两层含义

**总量匹配**（全机房热量能否被移走）：

$$Q_{\text{冷却系统可用}}\geq Q_{\text{IT}}+Q_{\text{UPS/PDU}}+Q_{\text{其他负荷}}$$

例：IT 发热 500 kW + UPS/配电/其他 ≈ 550 kW 总热负荷，则 CRAH、冷冻水、冷机、室外排热在当前工况都要能持续移走至少这部分热量并保留设计冗余。

**局部匹配**（总冷量够仍不够）：每个机柜、尤其高功率柜要获得与自身热负荷匹配的有效风量与冷量。

```text
机房总冷量充足
        +
某高功率机柜局部风量不足
        =
该机柜仍可能热点
```

例：总热负荷 300 kW、总可用冷量 400 kW 看似有余；但 15 kW 机柜附近送风不足或热回流，进风温度仍会升高——这不是总冷量不足，是局部气流组织与末端能力不匹配。

---

## 3. 要沿整条链路匹配

```text
IT 实际功率与机柜负荷
→ 单柜所需空气流量/冷量
→ CRAH / CRAC 的风机与盘管能力
→ 冷冻水或制冷剂的温度、流量、压差
→ 冷机能力
→ 冷却塔、干冷器等室外排热能力
```

任一环不足都限制最终能力。例如 CRAH 阀已全开，但冷冻水流量不足或供水温度过高，实际可用冷量就可能低于铭牌额定值。

---

## 4. 不等于铭牌相加

容量匹配看**实际可用冷量**，不是简单相加设备铭牌。实际能力受供水温度、回风温度、水流量、风量、盘管状态、部分负荷性能、室外环境影响。

| 概念 | 含义 |
|------|------|
| 安装容量 | 所有已安装设备的额定冷量之和 |
| 运行容量 | 当前开启设备在现场工况下实际可提供的冷量 |
| 冗余容量 | 为故障、检修保留的能力（如 N+1 中额外一台 CRAH） |
| 可扩展容量 | 保持冗余后，系统仍能安全承接的新增负荷 |

---

## 5. 一句话记忆

冷却容量匹配 = "热量产生多少、在哪里产生、以多快速度变化" 与 "系统能在实际工况下移走多少热量、并能否准确送到该位置" 相匹配。
