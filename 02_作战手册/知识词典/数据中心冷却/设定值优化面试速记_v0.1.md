# 设定值优化面试速记

> 定位：数据中心冷却设定值优化的口述速记。PUE 与冷却能耗链见 `PUE理解与冷却能耗链面试速记_v0.1.md`；部分负荷与台数控制见 `部分负荷与台数控制面试速记_v0.1.md`；CRAH 风机与冷冻水泵变频见 `CRAH风机与冷冻水泵变频节能面试速记_v0.1.md`；控制闭环、容量匹配、可靠性、监控的展开见 `数据中心冷却面试速记_v0.1.md`；水路设备见 `冷冻水冷却水系统与水泵控制面试速记_v0.1.md` 与 `水系统管路阀门水泵面试速记_v0.1.md`。

## 一、总原则（设定值优化的本质）

设定值优化的本质不是"把每个设定值调到最高或最低"，而是基于服务器进风温度、末端换热能力、最不利水力条件、冷却冗余和全系统功率，动态寻找系统总能耗最低的工作点。DOE 数据中心指南建议：送风温度和冷冻水供水温度应在满足冷却能力的前提下尽可能提高，同时通过冷冻水差压复位和冷凝水温度复位优化输配与冷源能耗。

四类设定值不是独立调节的，而是一条耦合链：

```
服务器进风温度 / 热点风险
  ↓ 约束
CRAH 送风温度
  ↓ 影响
CRAH 阀位、风量、盘管换热需求
  ↓
冷冻水供水温度、冷冻水压差与水泵频率
  ↓
冷机蒸发温度、冷凝水温度、冷却塔风机与水泵功率
  ↓
冷却系统总功率与 PUE
```

不应以"单台冷机 COP 最大"或"单台泵功率最低"为唯一目标。更接近工程实际的目标：

```
min P_cooling,total
s.t. T_rack,inlet ≤ T_limit
     Q_terminal ≥ Q_load
     Δp_critical ≥ Δp_required
     最小流量、冗余与设备运行约束满足
```

## 二、1. CRAH 送风温度

不是最终目标，服务器实际进风温度才是热安全约束。

不能盲目降低：送风温度过低通常增加冷却盘管负荷，也可能要求更低冷冻水温度，进而增加冷机压缩功。若冷通道存在旁通、热空气回流或气流分配不均，降低全机房送风温度未必解决高负荷机柜热点，却会让低负荷区域过冷、全系统能耗增加。

不能盲目提高：送风温度提高通常减轻末端与冷源负担，但高密度机柜温度裕度变小；一旦 IT 负荷突升、某台 CRAH 故障或气流组织恶化，最不利机柜可能更快超限。

控制口径：CRAH 送风温度应以高密度或最不利机柜的进风温度为安全约束，在气流组织、冗余状态和负荷变化允许时逐步上调，而非长期固定偏低值。上调后应同步观察关键机柜进风温度、CRAH 阀位、风机频率、送回风温差和热点数量，确认末端仍有冷量与风量余量。DOE 也建议用"最苛刻设备的进风温度"确定供风温度，实际工程往往保留一定误差与动态负荷裕量，而非把温度推至极限。

## 三、2. 冷冻水供水温度

主逻辑正确：在末端冷量、最热机柜进风温度和冗余裕量允许时，提高冷冻水供水温度通常降低冷机能耗，并可能扩大自然冷却可用时间。提高供水温度通常意味着蒸发温度相应提高、压缩机压比减小，冷机效率改善；同时更易与冷却塔/干冷器/板式换热器实现经济器或自然冷却协同。

必须补的边界——提高供水温度后不能只看冷机省电，还要看末端连锁反应：

| 可能收益 | 可能代价或风险 |
| --- | --- |
| 冷机蒸发温度提高，压缩机功耗可能下降 | CRAH 盘管进出水与空气温差减小，盘管可提供冷量下降 |
| 自然冷却所需室外条件更宽松，可用小时数增加 | 为维持盘管冷量，可能需要更高水流量或更大阀门开度 |
| 可能减少机械制冷运行时间 | 风机可能需提高风量，导致 CRAH 风机耗电增加 |
| 可能减少除湿需求或降低过度冷却风险 | 高密度区域、故障工况与负荷突升时的热安全余量下降 |

细工程点：变流量系统中，提高冷冻水温度可能使 CRAH 阀门进一步打开、流量需求增加，从而提高泵耗；ASHRAE 冷水系统控制资料强调冷冻水供水温度与差压设定值复位应协同，不能分别独立优化。

复位信号优先级：最热机柜进风温度及趋势（热安全上限）→ CRAH 阀位分布（末端冷量裕量代表）→ CRAH 送风温度、风机频率和冷冻水供回水温差 → 冷机实际 kW/冷量、泵功率、冷却塔功率（能效反馈）→ 湿度或露点限制（覆盖/回退）。相比固定室温或室外温度表复位，依据 CRAH 阀门真实开度、机柜进风温度与回水温度等"实际冷却需求"复位更适合数据中心显热主导的连续负荷场景。

## 四、3. 冷冻水压差

核心目标：以最低冷冻水泵功率，保证最不利 CRAH 盘管在需要时获得足够流量和压差。

差压过高：泵扬程和功率提高；大量两通阀被迫小开度节流，阀权度可能变差；某些支路流量过大造成水力失衡；若旁通或过流量明显，供回水温差偏小，冷机加载和输配效率变差。

差压过低：最不利支路无法获得设计或需求流量；关键 CRAH 阀门长期接近全开；CRAH 送风温度上升、最热机柜进风温度接近上限；某些区域先出现热点，即使总冷量尚有余量。

推荐复位方法：

| 方法 | 主信号 | 优点 | 注意点 |
| --- | --- | --- | --- |
| 最不利端差压控制 | 最远或阻力最大 CRAH 支路压差 | 逻辑直接、保障最不利端 | 传感器位置与可靠性十分关键 |
| 阀位复位 | 多个关键 CRAH 阀门开度 | 更贴近实际末端需求 | 阀门开度高不必然仅由压差不足引起 |
| 负荷预测复位 | IT 功率、机柜温度趋势 | 可提前应对负荷跃升 | 预测结果应受温度/压差硬约束 |
| 分区复位 | 每个 CRAH 服务区域测点与阀位 | 适合负荷不均机房 | 控制架构更复杂 |

最常见稳健思路：以关键末端阀门开度或最不利端压差为核心信号，逐步将差压设定压低；若出现关键阀门持续接近全开、末端流量不足或关键机柜温度上升，再回调。DOE 明确建议降低冷冻水供水压力设定并加入差压设定值复位控制序列。

与水温设定的顺序（最值得记住）：冷冻水供水温度上调使盘管换热温差变小、控制阀趋向开大；若同时把差压设定调低，可能造成阀门全开但水流不足、末端冷量骤降。因此冷冻水温度复位与差压复位必须联动，设置边界、步长和回退逻辑。ASHRAE 明确提示：冷冻水供水温度与差压设定值复位不能像独立 VAV 参数分别处理，应按顺序协调。

## 五、4. 冷却水温度（准确说法是"优化冷凝器进水温度设定"）

冷却水温度降低往往降低冷机冷凝温度与压缩机功耗；但为更低冷却塔出水温度，冷却塔风机和冷却水泵通常付出更多能耗。最终要优化：

```
P_plant = P_chiller + P_CW,pump + P_tower,fan
```

而不是单独最小化 `P_chiller`。

关键决定因素：室外湿球温度（冷却塔经蒸发换热排热，塔出水可达下限主要受湿球而非干球限制）；冷却塔 Approach（塔出水温度与室外湿球温度之差，更小 Approach 一般需更高塔风机功率或更大设备能力）；冷水机组特性（不同冷机对更低冷凝器进水温度收益不同）；冷却水泵与塔风机曲线（更低水温可能需更多水量或更高风量）；水资源（蒸发冷却塔涉及补水、排污、水处理和 WUE）。

冷却水温度复位常见依据为室外湿球温度、冷机负荷和实际冷站效率；但固定维持"湿球温度 + 某常数"不必然使全年总能耗最低，仍须根据具体冷机、泵塔曲线与现场趋势数据校准。

面试表达：冷却水温度越低通常越利于降低冷机冷凝压力和压缩机功耗；但冷却塔风机和冷却水泵为得到更低塔出水温度也会增加耗电，且蒸发冷却涉及水耗。应根据室外湿球温度、冷机负荷和泵塔/冷机实际功率，动态复位冷凝器进水温度设定，以最小化冷机、泵和塔风机组成的冷站总功率，而非单独追求最低冷却水温度。

## 七、可直接写入笔记

数据中心冷却能效优化很大一部分来自设定值复位，而不必依赖更换设备。设定值优化的目标不是让任意一个温度或压差越高、越低越好，而是在服务器进风温度、末端冷量、最不利端水力条件、设备最小流量和冗余要求满足的前提下，使 CRAH 风机、冷冻水泵、冷机、冷却水泵和冷却塔风机的总功率最低。

CRAH 送风温度应以最不利机柜进风温度为约束。送风温度过低会增加过度冷却和冷站能耗，且不能解决因热回流或气流分配不均造成的热点；送风温度过高则会缩小高密度区域和故障工况下的热安全余量。因此，应在关键机柜进风温度、热点趋势、CRAH 阀位和风机频率允许时，逐步上调送风温度。

冷冻水供水温度提高通常有利于提高冷机蒸发温度、降低压缩机功耗，并增加自然冷却可用机会；但会降低 CRAH 盘管的换热温差，可能导致阀门开大、泵耗或风机耗增加，并压缩高负荷工况下的冷量裕量。应根据机柜进风温度、CRAH 阀位、送风温度、供回水温差和全系统 kW/冷量进行动态复位。

冷冻水压差应以最低泵耗满足最不利 CRAH 所需流量为目标。压差过高会增加泵耗和阀门节流，压差过低则会使关键阀门全开、末端流量不足。可用最不利端差压或阀门开度执行压差复位；但冷冻水温度上调会使阀门趋于开大，因此供水温度和差压设定必须联动复位并设置回退逻辑。

冷却水温度应依据室外湿球温度、冷机负荷和冷站总功率进行优化。降低冷凝器进水温度通常可减少压缩机功耗，但会增加冷却塔风机、冷却水泵和水耗。系统应比较冷机、泵和塔风机的总功率，而不是单独追求最低冷却水温度。

## 八、60 秒面试版（口述模板）

数据中心设定值优化的原则是在服务器进风温度、末端冷量、最不利端压差、最小流量和冗余满足要求的前提下，最小化全冷却系统功率。CRAH 送风温度不能只看设备本体，应以最热机柜进风温度为约束；冷冻水供水温度可以在末端余量允许时上调，以降低冷机压缩功并增加自然冷却机会，但要同时观察盘管阀位、泵耗、风机耗和高负荷裕量。冷冻水差压则可以依据最不利端压差或关键阀位复位，避免泵长期高压差运行。对于冷却水温度，较低水温可降低冷机冷凝功耗，但会提高冷却塔风机、泵耗和水耗，因此最终要优化冷机、泵和冷却塔的总功率，而不是单独追求某台设备的最低能耗。
