## §1 制冷原理总览

### 一句话理解

蒸汽压缩制冷不是"制造冷量"，而是利用压缩机消耗的电功，把被冷却空间中的热量搬运到室外或其他高温侧环境。

### 完整循环链路

两种记法（等价）：

- 工程常用顺序（按设备动作）：**压缩 → 冷凝 → 节流 → 蒸发**
- 从"制冷效果从哪来"讲：**蒸发 → 压缩 → 冷凝 → 节流**

闭环：

```
蒸发器吸热 → 压缩机做功 → 冷凝器放热 → 节流装置降压 → 蒸发器吸热
```

### 四大部件

| 部件 | 制冷剂状态变化 | 核心作用 | 面试关键词 |
|------|----------------|----------|------------|
| 蒸发器 | 低压低温液汽混合物 → 低压蒸气 | 从被冷却对象吸热，产生制冷效果 | 吸热、汽化、低压侧 |
| 压缩机 | 低压蒸气 → 高压高温蒸气 | 抽吸、压缩并输送制冷剂；维持蒸发器低压 | 做功、升压、升温 |
| 冷凝器 | 高压高温蒸气 → 高压液体 | 向室外空气或冷却水放热，使制冷剂冷凝 | 放热、液化、高压侧 |
| 节流装置 | 高压液体 → 低压低温液汽混合物 | 降压、降温，并调节进入蒸发器的制冷剂流量 | 节流、降压、供液 |

#### 蒸发器
制冷系统真正"取冷"的位置：低压制冷剂在其中蒸发、汽化，从空气、水或物体吸热。
空调室内机盘管、冷库蒸发器、冷水机组蒸发器，本质都是把被服务对象的热量转移给制冷剂。

> 回答模板：蒸发器让低压低温制冷剂吸收被冷却对象的热量并汽化，实现制冷。对应低压侧，其蒸发压力决定蒸发温度。

#### 压缩机
从蒸发器吸入低压蒸气，压缩成高压高温蒸气；既推动循环，也维持蒸发器低压。
压缩后温度升高，才能高于室外空气/冷却水温度，从而在冷凝器向外放热。

> 回答模板：压缩机是循环动力中心。吸入低压蒸气并压缩，使压力温度升高，为冷凝器排热创造温差，同时维持蒸发器低压蒸发状态。

#### 冷凝器
系统排热端：高压高温蒸气把热量传给空气或冷却水后冷凝为高压液体。
排出热量 = 蒸发器吸收的热量 + 压缩机输入功转化的能量：

```
Q_cond = Q_evap + W_comp
```

> 回答模板：冷凝器向环境排热，使高压高温蒸气冷凝成高压液体。它是高压侧换热器，冷凝温度由室外空气/冷却水条件、换热面积和流量共同影响。

#### 节流装置
通常是热力膨胀阀、电子膨胀阀或毛细管。作用不是"主动制冷"，而是让高压液体经阻力迅速降压、降温，形成可在蒸发器吸热的低压状态。同时调节供液量，防止供液过多或不足。

> 回答模板：节流装置把高压液体降到蒸发压力，形成低压低温液汽混合物，并调节蒸发器供液量，为低温汽化创造条件。

### 完整循环（带低压/高压侧）

1. **蒸发器：吸热** — 节流后的低压低温制冷剂进入蒸发器，从室内空气/冷水/冷藏空间吸热并蒸发，出口为低压蒸气。
2. **压缩机：做功** — 吸入低压蒸气，消耗电功压缩为高压高温蒸气，压力温度明显升高。
3. **冷凝器：放热** — 高压高温蒸气进入冷凝器，向室外空气/冷却水排热，逐渐变为高压液体。
4. **节流装置：降压** — 高压液体流经膨胀阀/毛细管，压力骤降、温度降低，出口为低压低温液汽混合物，回到蒸发器。

#### 30 秒口述版
蒸汽压缩制冷循环由蒸发器、压缩机、冷凝器和节流装置构成。低压低温制冷剂先在蒸发器吸收室内或被冷却对象的热量并汽化；随后压缩机对低压蒸气做功，使其变成高压高温蒸气；制冷剂在冷凝器向室外空气或冷却水放热并冷凝为高压液体；最后经膨胀阀节流降压、降温，形成低压低温液汽混合物，再回到蒸发器继续吸热。

### 六个关键概念

#### 制冷量 Q₀
蒸发器单位时间从被冷却对象吸收的热量，即系统实际提供的"冷却能力"。单位常见 kW、W、RT。
- 房间负荷越大，需要的制冷量越大；蒸发器吸热越充分，制冷量越高。
- 制冷量 ≠ 压缩机功耗（前者是输出冷却效果，后者是获得该效果消耗的电功）。

#### 压缩机功耗 W_comp
压缩机为提升制冷剂压力和温度消耗的功率，通常是系统最主要电耗来源之一。
压缩比升高、冷凝压力升高或蒸发压力降低时，压缩机通常做更多功。

#### COP（性能系数）
制冷工况：

```
COP_cooling = Q₀ / W_comp
```

表示"每消耗 1 单位电功，获得多少单位制冷量"。COP=3 不是说效率 300%，而是 1 kW 电功可搬运约 3 kW 热量（搬运而非电能转冷量）。

热泵制热工况：

```
COP_heating = Q_cond / W_comp = COP_cooling + 1
```

（因 Q_cond = Q₀ + W_comp）

#### 蒸发温度
制冷剂在蒸发器内、对应蒸发压力下汽化的饱和温度。它**不等于**室内空气温度——蒸发器要从室内吸热，蒸发温度必须低于室内空气温度才能建立换热温差。

#### 冷凝温度
制冷剂在冷凝器内、对应冷凝压力下由蒸气凝结为液体的饱和温度。通常要高于室外空气/冷却水温度才能排热。

#### 制冷剂
系统工作介质，通过不同压力下的蒸发/冷凝把低温侧热量带到高温侧。理想制冷剂需兼顾热力性能、安全性、材料兼容性、环境影响、成本和系统适配性；选型不能只看制冷量。

> 深化版（基本作用、为什么能搬热、对制冷剂的基本要求、制冷 vs 热泵模式、COP 区别）见本文 §3。

### 过热度与过冷度

两者描述制冷剂相对饱和状态"偏离了多少温度"，是制冷面试高频词（完整定义、状态变化图、数值例子、压焓图位置、为什么需要、易混淆点见本文 §5）。

- 过热度：蒸气实际温度高于该压力饱和蒸发温度的差值。适当过热保证吸入干蒸气、防液击；过大则减少有效换热、影响效率。
- 过冷度：高压液体温度低于该压力饱和冷凝温度的差值。适当过冷减少节流前闪发、提高有效液体比例，但须结合工况判断。

### 蒸发温度与冷凝温度（最值得理解透）

> 为什么"蒸发温度低/冷凝温度高 → COP 降"：理论根源见本文 §2（逆卡诺 COP 公式 `T_c/(T_h−T_c)`）；机制深化（压缩比、各层能效影响、冷凝温度过高原因）见本文 §4。

#### 蒸发温度过低
蒸发温度降低 → 蒸发压力下降 →（冷凝侧不变时）压缩比增大 → 压缩机比功增加、吸气比容变大、单位功耗制冷量下降 → **COP 通常下降**。

> 标准回答：蒸发温度过低通常降低蒸发压力、增大压缩比，压缩机做功增加，单位功耗制冷量下降，COP 通常降低。应在满足供冷要求前提下，尽量避免不必要地设得过低。

#### 冷凝温度过高
冷凝温度升高 → 冷凝压力升高 → 压缩机排气端压力变高、压缩更困难、功耗增加；节流前液体状态和单位制冷量也可能变差 → **COP 通常下降**。

常见原因：室外空气温度过高；冷却水温度过高；冷凝器积尘/结垢/面积不足；风机/冷却塔/水泵异常；充注量或不凝性气体问题。

> 标准回答：冷凝温度过高使高压侧压力升高，排气压力和压缩功增大，制冷量可能下降，COP 降低。可通过改善换热、保持清洁、优化风量水量、合理控制冷却介质温度来降低。

#### 判断表（常规趋势，讲"通常/其他条件近似不变"最严谨）

| 参数变化 | 压缩比 | 压缩机功耗 | 制冷量趋势 | COP 趋势 |
|----------|--------|------------|------------|----------|
| 蒸发温度降低 | 通常增大 | 通常增加 | 往往下降 | 通常下降 |
| 蒸发温度升高 | 通常减小 | 通常下降 | 往往上升 | 通常上升 |
| 冷凝温度升高 | 通常增大 | 通常增加 | 往往下降 | 通常下降 |
| 冷凝温度降低 | 通常减小 | 通常下降 | 往往上升 | 通常上升 |

> 幅度受制冷剂种类、压缩机形式、换热器性能、部分负荷和控制策略影响。

### 制冷与热泵

核心循环原理相同，区别在于利用哪一侧作为有用效果。热泵通常借四通阀切换流向，使室内外换热器角色互换（详述见本文 §3）。

| 模式 | 有用效果 | 对室内作用 | 关键换热器 |
|------|----------|------------|------------|
| 制冷 | 蒸发器吸热量 Q₀ | 从室内取热，降温 | 室内侧蒸发器 |
| 热泵制热 | 冷凝器放热量 Q_cond | 向室内放热，升温 | 室内侧冷凝器 |

> 简答：制冷和热泵用相同蒸汽压缩循环，区别在于利用哪侧热量。制冷利用蒸发器从室内吸热；热泵利用冷凝器向室内放热。通常切换制冷剂流向使室内外换热器交换功能。

### 简单压焓图（p–h 图）

- 纵轴：压力 p（常用对数坐标）；横轴：比焓 h。
- 饱和液线与饱和蒸气线围成"饱和区/湿蒸气区"；左侧偏液体，右侧偏过热蒸气。

单级循环四个状态点：

| 状态点 | 位置/状态 | 对应部件出口 |
|--------|-----------|--------------|
| 1 | 低压蒸气，通常带过热 | 蒸发器出口 / 压缩机入口 |
| 2 | 高压高温过热蒸气 | 压缩机出口 |
| 3 | 高压液体，可能过冷 | 冷凝器出口 / 节流入口 |
| 4 | 低压低温液汽混合物 | 节流出口 / 蒸发器入口 |

四个过程：

- **1→2 压缩**：压力、焓值升高，压缩机输入功。
- **2→3 冷凝放热**：高压侧放热，焓值下降。
- **3→4 节流**：近似等焓，h₃ ≈ h₄。
- **4→1 蒸发吸热**：低压侧吸热，焓值升高。

> 至少能看懂：压缩机 1→2；冷凝器 2→3；节流阀 3→4；蒸发器 4→1。节流近似等焓；蒸发器对应制冷量；压缩机过程对应功耗。

### 高频面试问题

**为什么压缩机不是"制造冷量"？**
压缩机消耗电功，作用是提高制冷剂压力和温度，维持低压蒸发与高压冷凝之间的循环条件。真正吸热、产生制冷效果的是蒸发器。

**为什么高压侧一定要比环境温度高？**
热量只能自发从高温传向低温。冷凝器中的制冷剂必须高于室外空气/冷却水温度，才能排出蒸发器吸收的热量 + 压缩机输入功对应的热量。

**为什么低压侧一定要低于被冷却空间温度？**
蒸发器中的制冷剂必须比被冷却空气/水/物体温度低，才能吸热蒸发。因此蒸发温度需低于被冷却对象，但过低又降低能效——这是工程设计中的平衡。

**为什么不把蒸发温度设得越低越好？**
虽能获得更低供冷温度，但通常使蒸发压力降低、压缩比增加、压缩机功耗上升，COP 降低。正确做法：在满足冷却需求和换热温差前提下，尽量提高蒸发温度。

**为什么不把冷凝温度设得越低越好？**
通常降低冷凝温度有利于降压缩功、提 COP，但仍要满足向环境放热、液化及稳定运行的需要。工程上通过改善冷凝器换热来降低不必要的冷凝温度，而非无条件追求极低。

### 一分钟面试回答（整合版）

蒸汽压缩制冷循环由蒸发器、压缩机、冷凝器和节流装置组成。蒸发器内低压制冷剂吸热汽化，压缩机对低压蒸气做功并将其压缩为高压高温蒸气，冷凝器将热量排向环境并使制冷剂凝结为高压液体，节流装置再将其降压降温后送入蒸发器。系统制冷 COP 等于制冷量除以压缩机功耗；在其他条件近似不变时，蒸发温度过低或冷凝温度过高通常都会使压缩比增大、压缩机功耗上升、COP 下降。

## §2 卡诺与逆卡诺（理论上限）

> 来源：用户提供的卡诺循环/逆卡诺学习笔记（秋招空调制冷岗位准备），非本仓库代码。
> 口径：理论极限 + 面试表达，数值为示例，非某具体设备实测值。
> 衔接：本节解释本文 §1"蒸发温度低/冷凝温度高 → COP 降"的**理论根源**，建议先读 §1。

### 一句话理解

卡诺循环是完全理想、完全可逆的热力学循环，用来给出两个恒温热源之间热机效率的**理论上限**——它不是现实设备能完全实现的循环，而是评价实际热机、制冷机、热泵性能上限的"标尺"。

### 核心思想

卡诺循环工作在两个恒温热源之间：

- 高温热源：温度 `T_h`
- 低温热源：温度 `T_c`

由**两个等温过程**和**两个可逆绝热过程**组成。

正向卡诺热机从高温热源吸热 `Q_h`，向低温热源放热 `Q_c`，差额转化为对外净功：

```
W = Q_h − Q_c
```

### 四个过程

```
高温热源 Th
    │  吸热 Qh
    ▼
① 等温膨胀
    │
    ▼
② 绝热膨胀
    │
    ▼
③ 等温压缩
    │  放热 Qc
    ▼
低温热源 Tc
    │
    ▼
④ 绝热压缩
    └──────── 回到初始状态
```

1. **等温吸热膨胀**：工质与高温热源接触，在 `T_h` 不变下吸热并膨胀，对外做功。
2. **绝热膨胀**：与热源隔绝，继续膨胀对外做功，内能下降，温度从 `T_h` 降至 `T_c`。
3. **等温放热压缩**：工质与低温热源接触，在 `T_c` 不变下被压缩并向低温热源放热。
4. **绝热压缩**：再次隔绝热源，外界对工质做功，温度从 `T_c` 升回 `T_h`，回到起点。

### 效率上限

卡诺热机效率：

```
η_Carnot = 1 − T_c / T_h
```

`T_h`、`T_c` 必须使用**绝对温度 Kelvin**，不能直接用摄氏度。

含义：
- `T_h` 越高 → 效率上限越高。
- `T_c` 越低 → 效率上限越高。
- 只要 `T_c > 0 K`，效率就不可能达到 100%。

例：高温热源 500 K、低温热源 300 K：

```
η_Carnot = 1 − 300/500 = 0.40
```

理论最高效率 40%。现实热机还有摩擦、有限温差传热、压降、泄漏等不可逆损失，实际效率一定低于卡诺效率。

### 与制冷的关系（重点）

学蒸汽压缩制冷时更常用**逆卡诺循环**：正向卡诺是"吸热→输出功→向低温排热"；逆卡诺需要外界输入功，把热量从低温侧搬到高温侧——这正是制冷机和热泵的共同本质。

#### 逆卡诺制冷 COP

```
COP_R,Carnot = T_c / (T_h − T_c)
```

- `T_c`：蒸发器侧绝对温度（低温侧）
- `T_h`：冷凝器侧绝对温度（高温侧）

它直接解释"蒸发/冷凝温度影响 COP"的工程结论：
- **蒸发温度降低** → `T_c` 下降 → `T_h − T_c` 增大 → 理论 COP 降低。
- **冷凝温度升高** → `T_h` 上升 → `T_h − T_c` 增大 → 理论 COP 同样降低。

因此工程上通常希望在满足供冷要求前提下，**提高蒸发温度、降低冷凝温度**，缩小冷热端温差，降低压缩机搬热难度。

#### 逆卡诺热泵 COP

```
COP_HP,Carnot = T_h / (T_h − T_c) = COP_R,Carnot + 1
```

原因：热泵向高温侧提供的热量 = 从低温侧搬来的热量 + 压缩机输入功转化的热量。

### 与蒸汽压缩循环的区别

| 项目 | 卡诺循环 | 实际蒸汽压缩制冷循环 |
|------|----------|----------------------|
| 定位 | 理论效率或 COP 上限 | 工程上实际使用的制冷循环 |
| 过程 | 两个等温、两个可逆绝热过程 | 压缩、冷凝、节流、蒸发 |
| 不可逆性 | 理想可逆，无摩擦、无压降、无限小温差换热 | 存在摩擦、压降、有限换热温差等损失 |
| 膨胀过程 | 理想中需膨胀机回收功 | 通常用节流阀，近似等焓且有损失 |
| 用途 | 判断理论极限、理解温差影响 | 空调、冷水机组、冰箱、热泵等实际设备 |

关键点：卡诺循环不是现实空调压缩机内部"真正按四步发生"的过程；它告诉你任何实际制冷系统的 COP 都不可能超过该工况下的卡诺 COP。

### 面试版回答

卡诺循环是由两个可逆等温过程和两个可逆绝热过程组成的理想热力循环，用于给出两个热源温度之间热机效率的理论上限。对于制冷系统，更常参考逆卡诺循环，其最大 COP 只取决于蒸发侧和冷凝侧的绝对温度。它说明蒸发温度越低或冷凝温度越高，冷热端温差越大，理论 COP 就越低。因此，实际制冷系统通常通过提高蒸发温度、降低冷凝温度和减少换热、压降等不可逆损失来提升能效。

## §3 制冷剂的基本作用

> 来源=用户学习笔记，通用原理、非实测值，与仓库项目一/二（基于已发表小论文）区分。
> 衔接：总览见本文 §1；理论极限见本文 §2。

### 一句话定义
制冷剂也叫**冷媒、制冷工质、"雪种"**，是制冷系统中负责**搬运热量**的工作介质。它**不是"制造冷"**，而是在低温侧吸热、在高温侧放热，把热量从需要降温的地方转移到室外或其他环境中。

### 蒸汽压缩循环中的角色（相变搬运）
制冷剂在循环中依次完成：

```
蒸发器：低压制冷剂蒸发吸热
   ↓
压缩机：制冷剂被压缩，压力和温度升高
   ↓
冷凝器：高压制冷剂冷凝放热
   ↓
节流装置：制冷剂降压、降温
   ↓
返回蒸发器
```

### 为什么制冷剂能搬热？
因为制冷剂在**不同压力下沸点不同**，并且在蒸发、冷凝的**相变过程**中能吸收或释放大量**潜热**：
- **蒸发器低压侧**：制冷剂容易蒸发，从室内空气、冷冻水或被冷却物体中吸热；
- **冷凝器高压侧**：制冷剂容易冷凝，将吸收的热量 **+ 压缩机输入功对应的能量** 一起排给室外空气或冷却水。

一句话：**制冷剂通过"低压蒸发吸热、高压冷凝放热"的相变循环，把低温侧的热量搬到高温侧。**

### 对制冷剂的基本要求
理想制冷剂不仅要能有效制冷，还要兼顾工程安全和环境约束：
1. 合适的蒸发压力和冷凝压力；
2. 较好的换热与流动性能；
3. 化学稳定，与压缩机润滑油和材料兼容；
4. 尽量低毒、低可燃或可控风险；
5. 较低的**臭氧消耗潜能值（ODP）**和**全球变暖潜能值（GWP）**；
6. 成本、供应和维护条件可接受。

> 制冷剂的性质会直接影响系统制冷量、压缩机功耗、设备尺寸、运行安全和环境表现。

### 制冷与热泵（核心循环相同）
制冷模式和热泵模式的核心制冷剂循环是一样的：都要经过**压缩、冷凝、节流、蒸发**。区别**不是"有没有制冷剂"**，而是人们把**哪一侧的换热效果作为有用效果**。

| 项目 | 制冷模式 | 热泵制热模式 |
|---|---|---|
| 主要目标 | 从室内取走热量 | 向室内输送热量 |
| 室内换热器角色 | 蒸发器 | 冷凝器 |
| 室内侧发生什么 | 制冷剂蒸发吸热 | 制冷剂冷凝放热 |
| 室外换热器角色 | 冷凝器 | 蒸发器 |
| 室外侧发生什么 | 向室外排热 | 从室外空气、水或土壤取热 |
| 对室内效果 | 降温、通常伴随除湿 | 升温 |

#### 制冷模式
室内机/盘管是蒸发器：
```
室内空气 → 放热 → 室内蒸发器（制冷剂吸热并蒸发）→ 压缩机 → 室外冷凝器（向室外空气放热）→ 室外环境
```
制冷剂在室内蒸发器中吸热，室内空气温度下降；若盘管表面温度低于空气露点，水汽凝结，故**制冷常同时除湿**。

#### 热泵制热模式
通过**四通阀**切换流向，室内外换热器角色对调：室内机变冷凝器，室外机变蒸发器：
```
室外空气/水/土壤 → 放热 → 室外蒸发器（制冷剂吸热并蒸发）→ 压缩机 → 室内冷凝器（冷凝向室内放热）→ 室内空气
```
热泵**不是凭空产热**：一部分热来自室外空气/水源/地源，另一部分来自压缩机输入的电功；压缩机把低温侧吸收的热量提升到足以向室内放热的温度水平。

**为什么冬季室外也能取热？** 只要室外环境温度仍高于蒸发器内制冷剂的蒸发温度，热量仍可从室外传给制冷剂；压缩机再把低温低压蒸气压缩成更高温高压蒸气，使其在室内侧冷凝放热。

**低温限制**：室外温度越低 → 蒸发温度越低、压缩比越大 → 制热能力和 COP 下降；同时室外换热器可能结霜，需周期性除霜（空气源热泵低温环境重要运行问题）。

### COP 的区别
#### 制冷 COP
\[
COP_{cooling} = \frac{Q_{evap}}{W_{comp}}
\]
有用效果 = 蒸发器从室内吸收的热量（制冷量）。

#### 制热 COP
\[
COP_{heating} = \frac{Q_{cond}}{W_{comp}}
\]
有用效果 = 冷凝器向室内释放的热量。又因为：
\[
Q_{cond} = Q_{evap} + W_{comp}
\]
所以在同一循环条件下：
\[
COP_{heating} = COP_{cooling} + 1
\]
这不违反能量守恒——热泵除消耗电功外，还把室外低温热源的热量搬进了室内。

### 面试版回答
制冷剂是制冷系统中的工作介质，其基本作用是利用**低压蒸发吸热、高压冷凝放热**的相变过程，把热量从低温侧搬运到高温侧。制冷和热泵制热采用的核心循环相同（压缩、冷凝、节流、蒸发），区别在于**利用哪一侧的换热效果**：制冷模式下室内换热器是蒸发器，从室内吸热并向室外排热；热泵模式下通过四通阀改变制冷剂流向，室内换热器变成冷凝器向室内放热，室外换热器则作为蒸发器从环境吸热。

## §4 蒸发温度·冷凝温度与 COP（机制深化）

> 来源=用户学习笔记，通用原理、非实测值，与仓库项目一/二（基于已发表小论文）区分。
> 衔接：本文 §1 的"蒸发温度与冷凝温度"节，以及 §2 逆卡诺 COP 理论极限。

### 核心一句话
压缩机要把制冷剂从蒸发侧的低压提升到冷凝侧的高压；**两侧压力差越大，搬热越费力，COP 越低**。

### 两个关系（先记住）
- 蒸发温度 ↓ ⇒ 蒸发压力 `P_evap` ↓
- 冷凝温度 ↑ ⇒ 冷凝压力 `P_cond` ↑

压缩比近似为：
\[
r_p = \frac{P_{cond}}{P_{evap}}
\]
所以，**无论蒸发压力降低，还是冷凝压力升高，都会使压缩比通常增大**。

### 蒸发温度过低

蒸发温度是制冷剂在蒸发器中吸热、汽化时对应的饱和温度；它越低，对应的蒸发压力通常越低。

#### 为什么压缩比增大
冷凝侧压力近似不变时：
```
原工况：蒸发压力 → 较低压缩机吸气压力 → 压到冷凝压力
蒸发温度降低后：更低蒸发压力 → 压缩机必须从更低压力开始压缩 → 仍压到相近冷凝压力
```
即 `P_evap ↓ ⇒ P_cond/P_evap ↑`。

#### 为什么能效下降（几层影响）
1. **压缩比增大**：压缩机跨越更大的压力差；
2. **单位质量制冷剂压缩功通常增加**：把制冷剂"抬升"到高压侧更费电；
3. **吸气比容增大、输气系数下降**：定容积压缩机同样排量下实际吸入的制冷剂质量可能减少；
4. **单位容积制冷量下降**：压缩机每转一圈能提供的冷量往往变少；
5. **排气温度升高**：压缩机工作条件变差，运行风险与损失增加。

于是制冷量往往下降或增长不足，而单位冷量所需功增加：
\[
COP_{cooling} = \frac{Q_{evap}}{W_{comp}} \quad \Rightarrow \quad COP↓
\]

#### 直观理解
把蒸发温度降低，相当于要求系统从"更冷的地方"取热。热量要从更低温侧被搬到相同室外高温侧，压缩机需完成更大的"温度提升"和"压力提升"，因此更费功。

但**蒸发温度并非越高越好**：蒸发器内制冷剂必须低于被冷却空气/冷冻水温度，才有足够换热温差吸热。工程原则——**在满足供冷温度和换热需求前提下，尽量提高蒸发温度**。

### 冷凝温度过高

冷凝温度是制冷剂在冷凝器中向冷却水或室外空气放热、由蒸气冷凝为液体时对应的饱和温度。冷凝温度升高 ⇒ 冷凝压力通常升高。

#### 为什么压缩比增大
蒸发侧压力近似不变时：
```
原工况：蒸发压力 → 压缩机 → 较低的冷凝压力
冷凝温度升高后：蒸发压力 → 压缩机 → 更高的冷凝压力
```
即 `P_cond ↑ ⇒ P_cond/P_evap ↑`。

#### 为什么压缩机功耗增加
排气端背压更高，压缩机不仅要把制冷剂压到更高压力，压缩过程终了温度、比功和排气温度通常也上升，带来：
- 输入功增大；
- 排气温度和高压侧压力上升；
- 输气系数可能下降；
- 实际制冷量可能减小；
- 冷凝器排热困难，系统运行条件恶化。

即"分子（制冷量）变小或不利、分母（压缩机功耗）增加" → COP 下降。

#### 为什么会冷凝温度过高（常见原因）
- 室外环境温度较高；
- 冷却塔能力不足、风机未充分运行；
- 冷却水温度高或流量不足；
- 冷凝器结垢、积灰或换热面积不足；
- 风冷冷凝器通风差、翅片脏堵；
- 系统内存在不凝性气体等异常。

> 对冷水机组：冷却塔、冷却水泵和冷凝器清洁度都影响冷凝温度，最终影响冷机能耗。

### 用卡诺 COP 理解（理论极限）
逆卡诺制冷机理论 COP：
\[
COP_{R,Carnot} = \frac{T_e}{T_c - T_e}
\]
- `T_e`：蒸发温度（K）
- `T_c`：冷凝温度（K）

| 工况变化 | 分子 | 分母 `T_c−T_e` | 理论 COP |
|----------|------|----------------|----------|
| 蒸发温度 `T_e` 降低 | 变小 | 变大 | 降低 |
| 冷凝温度 `T_c` 升高 | 不变 | 变大 | 降低 |

这只是理论极限，但方向与实际蒸汽压缩循环一致：**冷热端温差越大，搬热越困难，COP 越低**。

### 两句话怎么背
- **蒸发温度降低**：对应蒸发压力下降；冷凝压力近似不变时，压缩比增大，压缩机单位制冷量耗功增加，同时制冷量和输气效率通常下降 → COP 降低。
- **冷凝温度升高**：对应冷凝压力上升；蒸发压力近似不变时，压缩机必须把制冷剂压到更高排气压力，压缩功和排气温度通常增加，制冷量可能下降 → COP 降低。

## §5 过热度与过冷度（深化）

> 来源：用户提供的过热度/过冷度深化学习笔记（秋招空调制冷岗位准备），非本仓库代码。
> 口径：概念性原理 + 面试表达，数值为示例，非某具体机组实测值。
> 衔接：本节深化本文 §1 的"过热度与过冷度"一节，建议先读 §1。

### 一句话理解

- **过热度**看低压蒸气有没有"完全汽化并再升温"。
- **过冷度**看高压液体有没有"完全液化并再降温"。
- 它们都是"实际温度"相对"同一压力下饱和温度"的温差。

### 核心定义

| 概念 | 发生位置 | 本质 | 计算式 |
|------|----------|------|--------|
| 过热度 SH | 蒸发器出口、吸气管、压缩机入口 | 蒸气温度高于该压力下饱和蒸发温度多少 | `SH = T_actual,vapor − T_sat,evap` |
| 过冷度 SC | 冷凝器出口、液管、节流装置入口 | 液体温度低于该压力下饱和冷凝温度多少 | `SC = T_sat,cond − T_actual,liquid` |

> 注意：这里的"饱和温度"必须由**测量位置对应的制冷剂压力**查表或仪表换算得到，不能直接拿室内温度、室外温度代替。

### 状态变化图

#### 低压侧：蒸发器 → 吸气管 → 压缩机

```
液汽混合物 ── 吸热、完全汽化 ──> 饱和蒸气 ── 再吸一点热 ──> 过热蒸气
                                                    ↑
                                                这段温差
                                                = 过热度
```

#### 高压侧：压缩机 → 冷凝器 → 液管 → 节流装置

```
过热蒸气 ── 放热、冷凝 ──> 饱和液体 ── 再降一点温 ──> 过冷液体
                                                   ↑
                                               这段温差
                                               = 过冷度
```

一句话记忆：
- **过热度**：蒸气"超过刚好蒸干"又升了多少度。
- **过冷度**：液体"低于刚好凝完"又降了多少度。

### 数值例子

#### 过热度例子
蒸发器出口吸气压力对应饱和温度 = 5 ℃；实际测得吸气管温度 = 11 ℃。

```
SH = 11 − 5 = 6 ℃
```

制冷剂已完全变成蒸气，并在该压力下额外升温 6 ℃。过热度反映蒸发器出口蒸气的"干燥程度"。

#### 过冷度例子
冷凝器出口液管压力对应饱和冷凝温度 = 45 ℃；实际测得液管温度 = 39 ℃。

```
SC = 45 − 39 = 6 ℃
```

制冷剂已完成液化，并在高压侧又被冷却 6 ℃，成为稳定的过冷液体。

### 放到完整循环里

```
                        高压侧
                  ┌──────────────────┐
                  │                  ▼
             ┌─────────┐        ┌─────────┐
             │ 压缩机  │ ────→  │ 冷凝器  │
             └─────────┘        └─────────┘
                  ▲                  │
                  │                  │ 高压液体
          低压过热蒸气               │
          （看过热度）                ▼
             ┌─────────┐        ┌─────────┐
             │ 蒸发器  │ ←────  │ 节流阀  │
             └─────────┘        └─────────┘
                  ▲
                  │ 低压液汽混合物
                  └──────────────────────
```

冷凝器出口/液管：  饱和液体 → 过冷液体   （看过冷度）
蒸发器出口/吸气管：饱和蒸气 → 过热蒸气   （看过热度）

横轴比焓 h，纵轴压力 p。中间"穹顶"是液体和蒸气共存的饱和两相区：左边更接近液体，右边更接近蒸气。


图中：
- **1s→1**：低压饱和蒸气变成低压过热蒸气，对应过热度。
- **3s→3**：高压饱和液体变成高压过冷液体，对应过冷度。
- **1→2**：压缩机压缩过程。
- **2→3**：冷凝器放热过程。
- **3→4**：节流过程，理论分析近似等焓。
- **4→1**：蒸发器吸热过程。

### 为什么要有过热度

适当过热的最重要目的：确保进入压缩机的是**干蒸气**，而不是带液制冷剂。

若压缩机吸入液滴，液体几乎不可压缩，可能造成**液击**、润滑油稀释或机械损伤。因此蒸发器出口通常保留一定过热度，热力膨胀阀系统还会利用过热度控制阀门开度。

但过热度不是越大越好：

| 过热度情况 | 可能含义 | 风险或结果 |
|------------|----------|------------|
| 过低 | 蒸发器供液可能偏多，蒸气未完全干燥 | 带液回气、液击风险 |
| 适当 | 保证压缩机吸入干蒸气 | 运行较稳定 |
| 过高 | 蒸发器后段可能主要在加热蒸气，供液可能偏少 | 有效蒸发面积减少、吸气和排气温度升高，性能可能变差 |

> 面试里不要死背"标准数值"——合理范围受制冷剂、阀型、机组类型、控制策略和测点位置影响。讲清"适度是保护，过大可能损失效率"即可。

### 为什么要有过冷度

适当过冷的主要目的：确保节流装置前进入的是**稳定液体**，而不是含闪发气体的两相制冷剂。

若液管内已提前汽化，进入膨胀阀的有效液体减少，节流供液稳定性和蒸发器制冷能力都会受影响。因此适当过冷有助于降低液管闪发风险，通常能增加节流后可用于蒸发吸热的有效液体比例，提高单位质量制冷量。

| 过冷度情况 | 可能含义 | 风险或结果 |
|------------|----------|------------|
| 过低 | 液体接近饱和，液管稍降压就可能闪发 | 节流供液不稳定、制冷量受影响 |
| 适当 | 节流前为稳定液体 | 供液可靠，通常有利于制冷能力 |
| 过高 | 可能与过量充注、冷凝器储液或工况异常有关，需结合系统判断 | 不应机械追求越大越好 |

### 最容易混淆的点

#### 过热度不是排气温度
调试中最常说蒸发器出口或压缩机吸气侧过热度：

```
SH = T_suction − T_sat(P_suction)
```

压缩机排气侧也可能存在过热蒸气，但"排气温度"不能等同于日常所说的蒸发器过热度。面试时优先把过热度解释为：**吸气温度减去吸气压力对应的饱和温度**。

#### 过冷度不是"液体结冰"
制冷中的过冷度是相对于冷凝压力下的饱和冷凝温度，不是说液体低于凝固点、更不是"结冰"。

例：高压侧冷凝温度 45 ℃，实际液管 39 ℃，已经是 6 ℃过冷；它当然仍是液态制冷剂。

#### 温差单位可用 ℃ 或 K
过热度/过冷度都是温度差，用摄氏度或 Kelvin 数值相同：`6 ℃ = 6 K`。

### 面试版回答

过热度是蒸发器出口或压缩机吸气侧制冷剂蒸气的实际温度，高于该压力对应饱和蒸发温度的差值。适当过热可以确保进入压缩机的是干蒸气，防止液击；但过热度过大可能说明蒸发器供液不足或有效换热面积利用不充分。

过冷度是冷凝器出口液态制冷剂的实际温度，低于该压力对应饱和冷凝温度的差值。适当过冷可以保证节流阀前是稳定液体，减少液管闪发，并通常有利于提高有效制冷量。两者都不能只看温度本身，而要结合对应测点的压力换算饱和温度来判断。
