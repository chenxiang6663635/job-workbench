# 制冷循环与 COP 速查卡

> 汇总自：制冷原理、卡诺循环、制冷剂基本作用、蒸发冷凝温度与COP、过热度过冷度 五份速记。两线共用底座：空调制冷/HVAC、数据中心冷却。

## 一、循环骨架（四个部件）

| 部件 | 制冷剂状态 | 作用 | 关键词 |
|------|------------|------|--------|
| 蒸发器 | 低压液汽混 → 低压蒸气 | 吸热汽化，产生制冷效果 | 低压侧、吸热 |
| 压缩机 | 低压蒸气 → 高压高温蒸气 | 做功升压升温，维持蒸发器低压 | 动力、做功 |
| 冷凝器 | 高压蒸气 → 高压液体 | 向环境排热并冷凝 | 高压侧、放热 |
| 节流装置 | 高压液体 → 低压低温液汽混 | 降压降温、调节供液量 | 供液、降压 |

环路：蒸发 → 压缩 → 冷凝 → 节流 → 回蒸发。制冷不是"制造冷量"，而是压缩机耗功把热量从低温侧搬到高温侧。

## 二、关键量

- 制冷量 Q₀：蒸发器单位时间吸热量（输出冷效果），**不等于**压缩机功耗。
- 制冷 COP = Q₀ / W_comp；热泵 COP_heating = Q_cond / W_comp = COP_cooling + 1（因 Q_cond = Q₀ + W_comp）。
- 冷凝器排热 Q_cond = Q₀ + W_comp。

## 三、蒸发/冷凝温度对 COP（面试高频）

逆卡诺 COP = T_c / (T_h − T_c)。蒸发温度↓ 或 冷凝温度↑ → 冷热端温差↑ → 压缩比↑ → 功耗↑、COP↓（其他条件近似不变）。

- 蒸发温度过低：蒸发压力↓ → 压缩比↑ → 单位冷量耗功↑ → COP↓；但蒸发温度须低于被冷却对象才能吸热，故"在满足换热需求前提下尽量提高蒸发温度"。
- 冷凝温度过高：冷凝压力↑ → 排气压力与压缩功↑ → COP↓。常见原因：室外气温高、冷却塔/冷却水泵异常、冷却水温度过高或流量不足、冷凝器脏堵结垢、系统有不凝性气体。

## 四、过热度 / 过冷度

- 过热度 SH = T_实际蒸气 − T_饱和蒸发(对应吸气压力)。适度保证干蒸气防液击；过大说明供液不足、有效换热面积利用不充分。
- 过冷度 SC = T_饱和冷凝 − T_实际液体(对应液管压力)。适度减少节流前闪发、提高有效液体比例；非越大越好。
- 二者都须结合测点压力换算饱和温度，不能直接拿室内/外温度代替。

## 五、压焓图（p–h）四个状态点

1 低压过热蒸气(蒸发器出口/压缩机入口) → 2 高压过热蒸气(压缩机出口) → 3 高压液体(冷凝器出口/节流入口) → 4 低压液汽混(节流出口) → 1。1→2 压缩；2→3 冷凝放热；3→4 近似等焓节流；4→1 蒸发吸热。

## 六、制冷 vs 热泵

核心循环相同，区别在利用哪一侧：制冷用蒸发器从室内吸热；热泵用冷凝器向室内放热（四通阀切换流向）。低温限制：室外温度越低 → 蒸发温度↓ → 制热能力与 COP↓，且室外换热器可能结霜需除霜。

## 反例（面试必避）

1. "压缩机产生冷量" —— 错，真正制冷在蒸发器；压缩机只搬运热量。
2. "蒸发温度越低制冷越好" —— 错，过低降 COP，应在满足换热前提下尽量提高。
3. "过热度=排气温度""过冷度=液体结冰" —— 错，过热度是吸气温度减吸气压力对应饱和温度；过冷度是相对冷凝压力饱和温度，液体仍是液态。

## 记忆

制冷=搬运热，COP看温差；蒸发尽量高、冷凝尽量低；过热防液击、过冷防闪发；节流近似等焓。
