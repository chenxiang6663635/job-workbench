## 三侧分工

### 冷冻水侧
任务：把冷量送到末端，把室内热量带回机组。

```
蒸发器 → 冷冻水泵 → AHU / FCU → 冷冻水回水 → 蒸发器
```

主要设备：冷水机组内蒸发器、冷冻水泵、AHU（空气处理机组，集中处理较大风量）、FCU（风机盘管，房间/局部分区）、水管/阀门/过滤器/平衡阀/集分水器。

> 管路层级、阀门功能分类、FCU 支路组成、离心泵与变频相似定律、水力平衡原理，见 `水系统管路阀门水泵面试速记_v0.1.md`（组件级展开）。

冷冻水从蒸发器出来温度较低，流到 AHU/FCU 盘管吸收空气热量；水温升高后作为回水返回蒸发器，再由制冷剂带走热量。

### 冷却水侧
任务：把冷凝器侧的热量转移到室外。

```
冷凝器 → 冷却水泵 → 冷却塔 → 冷却水回水 → 冷凝器
```

主要设备：冷水机组内冷凝器、冷却水泵、冷却塔、水管/阀门/过滤器/补水与水处理设备。

注意水流顺序：冷凝器出口的冷却水温度更高，先去冷却塔；冷却塔降温后的水再返回冷凝器。

冷却塔排掉的热量不只是室内负荷，还包括压缩机耗电最终转化的热量：

```
Q_tower ≈ Q_cooling + W_compressor
```

冷却塔承担的是整个制冷系统的最终排热任务。

### 制冷剂侧
任务：将蒸发器中得到的低温热量"抬升"到冷凝器侧，以便向冷却水放热。

```
蒸发器 → 压缩机 → 冷凝器 → 节流装置 → 蒸发器
```

冷冻水、冷却水和制冷剂一般是三条相互隔离的流路：冷冻水通过蒸发器与制冷剂换热，冷却水通过冷凝器与制冷剂换热，二者不应直接混合。

### 冷冻水 vs 冷却水（高频基础题）

| 对比项 | 冷冻水 | 冷却水 |
|--------|--------|--------|
| 服务对象 | 室内 AHU、FCU 等末端 | 冷凝器、冷却塔 |
| 主要任务 | 把冷量送至末端、从室内取热 | 从冷凝器取热、向室外排热 |
| 所在侧 | 蒸发器侧，低温侧 | 冷凝器侧，高温侧 |
| 温度变化 | 供水较低温，回水升温 | 去塔水较高温，回塔水降温 |
| 关键泵 | 冷冻水泵 | 冷却水泵 |
| 热量去向 | 从室内带至蒸发器 | 从冷凝器带至冷却塔 |

一句话区分：**冷冻水服务室内，冷却水服务冷凝器和冷却塔。** 冷冻水把室内热量带到冷水机组；冷却水把冷水机组的热量带到室外。

## 风冷与水冷

两者制冷剂循环原理相同，核心区别在于**冷凝器如何排热**。水冷通过冷却水把热量送至冷却塔；风冷依靠风机驱动室外空气穿过翅片冷凝器直接排热，通常不需要冷却塔和冷却水泵。

| 项目 | 水冷冷水机组 | 风冷冷水机组 |
|------|--------------|--------------|
| 冷凝器冷却介质 | 冷却水 | 室外空气 |
| 是否有冷却塔 | 有 | 通常无 |
| 是否有冷却水泵 | 有 | 通常无 |
| 系统复杂度 | 较高 | 较低 |
| 典型适用 | 大型集中式、长运行时间项目 | 中小型、改造、缺水或机房条件有限项目 |
| 高环境温度影响 | 相对较小，取决于冷却塔湿球条件 | 较明显，受室外干球温度影响 |
| 维护重点 | 水处理、结垢、冷却塔、泵 | 风机、盘管积灰、通风散热 |

> 不要说"水冷一定好、风冷一定差"。正确表述：选择取决于建筑规模、运行时长、当地气候和水资源、机房与屋面条件、初投资和运维能力。

### VRF（多联机）vs 冷水机组（横向对照）
冷水机组与 VRF 的核心区别在**末端输送介质**：冷水机组用冷冻水把冷量送到 AHU/FCU；VRF 用制冷剂直接通过铜管进室内机盘管处理房间负荷。完整对照表（末端介质、设备、分区、规模、运维、选型权衡）见 `VRF与DOAS组合及节能机理面试速记_v0.1.md` 第1节（VRF vs 冷水机组横向对照正本）。

> VRF 与项目二（DOAS+VRF）的关联、以及"为什么 DOAS 节能远大于 VRF"的机理，见 `VRF与DOAS组合及节能机理面试速记_v0.1.md`；VRF/DOAS/CRAC/CRAH 四概念分类与总对比，见 `VRF_DOAS_CRAC_CRAH四概念对比面试速记_v0.1.md`。

## 一次泵与二次泵

### 一次泵系统
冷冻水泵直接服务"冷水机组蒸发器 + 建筑末端"这一回路：

```
冷水机组蒸发器 → 一次冷冻水泵 → 末端 → 蒸发器
```

特点：系统相对简单；设备和控制点少；机组侧与末端侧流量耦合较紧；常见于规模较小、工况较简单的系统。

### 一次、二次泵系统
把机组侧与末端侧水力回路分开：

```
一次侧：冷水机组蒸发器 ↔ 一次泵 ↔ 一次侧管路
                 ↓ 水力解耦 / 低阻旁通 / 解耦管
二次侧：二次泵 → 建筑末端 → 回水 → 二次泵
```

特点：一次泵保证机组蒸发器所需流量；二次泵按末端实际负荷调节流量；机组侧与用户侧流量可不同；更适合较大、末端多、负荷变化明显的系统；更灵活但设备、控制和调试更复杂。

> 面试版：一次泵系统中机组侧和末端侧共用同一组冷冻水泵，流量耦合紧、系统简单。一次、二次泵系统则将机组侧与末端侧水力解耦：一次泵保证冷机蒸发器流量，二次泵按末端负荷调节建筑侧流量，适合规模更大、负荷变化更明显的系统，但控制复杂度和初投资更高。

## 为什么供回水温差影响流量

冷量关系：

```
Q = ṁ · c_p · ΔT
```

- Q：所需冷量
- ṁ：水的质量流量
- c_p：水的比热容
- ΔT：供回水温差

冷量 Q 一定时：

```
ṁ = Q / (c_p · ΔT)
```

供回水温差越大，所需水流量越小。例如同样输送 100 kW 冷量：

| 供回水温差 | 所需水流量趋势 |
|------------|----------------|
| 5 ℃ | 流量较大 |
| 10 ℃ | 流量约可减半 |

水流量减少有利于降低泵功率和管网输送能耗（泵功率大致与流量和扬程乘积有关，管路阻力随流量增大显著增加）。

但不能追求无限大温差：末端盘管需足够换热能力；温差过大可能要求更大盘管面积或改变送风条件；低负荷下控制阀、流量和温差可能失配。"低温差综合征"是大型冷水系统常见运行问题——末端实际温差小于设计值，导致为满足冷量需更大流量，泵耗增加，机组和管网运行更不利。

> 面试简答：冷量一定时，冷量=水流量×水比热×供回水温差，故温差增大可降低所需流量；流量降低后泵功率和输送能耗通常下降。但温差受末端盘管换热、送风条件和控制策略限制，不能只追求更大温差。

## 为什么设备要协同控制

冷水机组系统不是"冷机开了就行"。冷机、冷冻水泵、冷却水泵、冷却塔任一环节不匹配，都会使系统能耗增加或运行不稳定。

| 设备 | 主要控制目标 | 与其他设备的协同关系 |
|------|--------------|----------------------|
| 冷水机组 | 按负荷提供冷量，维持供水温度 | 与冷冻水流量、冷却水温度和多机启停联动 |
| 冷冻水泵 | 满足末端流量和差压需求 | 随阀门开度、末端压差或流量需求变频 |
| 冷却水泵 | 保证冷凝器侧流量 | 与机组负荷、冷凝器压差、冷却塔能力协调 |
| 冷却塔 | 降低冷却水温度 | 与室外湿球温度、冷凝压力和塔风机能耗权衡 |
| AHU/FCU 阀门 | 按区域负荷调节水量 | 影响末端流量、回水温度和系统压差 |

典型协同逻辑：冷却塔风机开太小→冷却水温偏高→冷凝温度上升→压缩机功耗显著增加；但若不管室外条件一直开最大→又浪费塔风机电耗。合理控制应在"塔风机耗电"与"冷机因冷凝温度变化产生的耗电"间找系统总能耗最低点。

> 这就是为什么工程上应看**系统级能效**，而不是只看冷水机组本体 COP。

### 空调制冷方向
今天学的内容直接对应：中央空调系统、冷水机组、产品应用、系统方案、设备选型、调试和节能优化。

你要能回答：**为什么大型公共建筑常采用冷水机组系统，而小型建筑可能采用多联机（VRF）？**

**回答思路（7 个维度，按此展开最稳）**：
1. 建筑规模（冷量大小、负荷集中程度）；
2. 同时使用系数（大型建筑负荷叠加更平稳、更适合集中系统）；
3. 分区控制（末端数量与分区灵活度需求）；
4. 初投资（机房、水系统、塔、泵 vs 简洁安装）；
5. 运行维护（专业集中运维 vs 分散设备）；
6. 系统能效（大型系统适合变频、群控、冷却塔优化等系统级手段）；
7. 安装空间（是否具备机房、竖井、冷却塔条件）。

冷水机组适合大型公共建筑：能集中制冷、通过水系统服务大量末端与分区，便于大冷量、多区域、长期运行下的系统级优化；但机房/冷却塔/泵/管网/运维要求更高。VRF 适合中小型建筑、改造或分区灵活场景：安装灵活、无需大型水系统；但规模很大、内外机管网极复杂时，其集中管理、冗余设计和长期系统效率未必优于冷水机组。

| 维度 | 大型公共建筑：常见冷水机组 | 中小建筑：常见多联机 |
|------|----------------------------|----------------------|
| 建筑规模与冷量 | 大冷量、集中负荷 | 中小冷量、负荷分散 |
| 末端与分区 | AHU、FCU 服务大量区域 | 室内机分区灵活 |
| 初投资 | 机房、水系统、塔和泵较高 | 系统较简洁，安装通常较快 |
| 运行维护 | 专业运维要求高 | 分散设备维护，管理相对直观 |
| 能效优化 | 适合系统级变频、群控、冷却塔优化 | 部分负荷和分区控制有优势 |
| 安装条件 | 需机房、竖井、冷却塔等空间 | 需室外机位置与制冷剂管路条件 |

> 不要绝对化。正确结论：系统选型是多目标工程权衡，不是冷水机组与多联机的简单优劣比较。

### 数据中心方向
冷水机组系统也是很多数据中心冷却架构的重要组成部分。迁移逻辑：冷水机组产生冷冻水，冷冻水可以服务精密空调、机房空气处理设备（如 CRAH、AHU），也可以通过**板式换热器等换热设备服务液冷二次侧**。

但数据中心不是"把办公楼空调直接搬过去"，需主动说明差异：

| 普通建筑冷水系统 | 数据中心冷却系统 |
|------------------|------------------|
| 负荷随人员、围护结构和气象显著波动 | IT 负荷高、连续性强、热密度高 |
| 舒适性是主要目标 | 设备可靠性、温湿度边界和业务连续性是核心 |
| 可接受一定局部负荷波动 | 更强调冗余、容错、监控与故障切换 |
| 常规分区空调控制 | 更强调机柜/列级/机房级的精细气流与冷量匹配 |

> 迁移逻辑：制冷剂循环、冷冻水输送和冷却水排热的基本原理一致；数据中心是在更高可靠性、更高热密度和更精细控制要求下应用这套原理，而不是完全另一套制冷原理。数据中心空气侧（CRAC/CRAH、冷热通道、与舒适性空调五点差异）见 `空气侧处理与焓湿图面试速记_v0.1.md`。

## 1 分钟总回答

水冷冷水机组系统包括制冷剂循环、冷冻水循环和冷却水循环。冷水机组蒸发器制取低温冷冻水，冷冻水泵把它送到 AHU 或 FCU，冷冻水在末端吸收室内热量后回到蒸发器。制冷剂在机组内将这部分热量提升到冷凝器侧，再传给冷却水；冷却水由泵送往冷却塔，将热量排到室外后返回冷凝器。冷冻水服务室内末端，冷却水服务冷凝器与冷却塔，二者不能混淆。系统运行时需要让冷机、水泵、冷却塔和末端阀门协同控制，才能在满足供冷需求的同时降低整体能耗。
