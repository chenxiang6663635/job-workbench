# 水系统与水泵控制速查卡

> 汇总自：水系统管路阀门水泵、冷冻水冷却水系统与水泵控制 速记。支撑空调制冷与数据中心共同问题。

## 一、两套水路（水冷冷水机组）

- 冷冻水侧：蒸发器 → 冷冻水泵 → AHU/FCU/CRAH 盘管 → 回水 → 蒸发器。输送冷量。
- 冷却水侧：冷凝器 → 冷却水泵 → 冷却塔 → 回冷凝器。排放冷凝热。

两路在冷机内通过制冷剂间接换热，水不混合。冷却塔排热 Q_tower ≈ Q_cond = Q_evap + W_comp（含压缩机输入功转化的热）。

## 二、冷量输送关系

Q = ṁ·c_p·ΔT。冷量一定时，供回水温差 ΔT 越大 → 所需流量越小；但温差过小（低温差综合征）→ 被迫大流量 → 泵耗↑、管网运力↓。流量过低则盘管换热不足、末端供冷能力下降。

## 三、三类水泵系统

一次定流量（冷机侧与末端流量固定，简单但部分负荷节能有限）、一次泵—二次泵（冷机侧与负荷侧解耦，适合大系统）、一次变流量（同组泵随末端变流量，须保蒸发器最小流量与流量变化率）。

## 四、变频与相似定律

Q ∝ n，H ∝ n²，P ∝ n³。部分负荷降速 → 功率下降更快，节能潜力大；但实际受静压、泵效率、最小流量约束，不能无限降速。压差控制：末端阀关小 → 不利环路压差升 → 降泵频 → 流量、扬程、功率降。

## 五、冷却塔（冷却水侧排热）

蒸发为主、显热对流为辅。Range = T_in − T_out（降几度）；Approach = T_out − T_wb（出水离湿球蒸发冷却下限多远）。湿球温度决定冷却下限，非干球。降出水温利于冷机但增风机耗，须系统协同优化冷机+水泵+冷却塔总功耗。

## 六、阀门与水力平衡

阀门：隔离、调节（二通/三通）、平衡、止回、排气、排污。FCU 支路典型：截止阀 → 过滤器 → 电动二通阀 → 盘管 → 平衡阀 → 回水。水力平衡：水走阻力小路径，不平衡则近端抢水远端缺水；用平衡阀、压差控制、变频按最不利环路运行解决。

## 反例（面试必避）

1. "冷冻水=冷却水" —— 错，前者输冷量后者排冷凝热，两路不混。
2. "变频泵转速越低越节能" —— 错，须满足最小流量、换热与压差，过低反损。
3. "VWV 变水量 = VAV 变风量 = VRF 变制冷剂" —— 错，三者变的介质分别是水/空气/制冷剂，系统层级不同。

## 记忆

冷冻水送冷、冷却水排热，两路不混；Q=mcpΔT，温差大流量小；泵耗∝转速³，压差反馈降频；冷却塔看 Range/Approach，湿球定下限；平衡防抢水。
