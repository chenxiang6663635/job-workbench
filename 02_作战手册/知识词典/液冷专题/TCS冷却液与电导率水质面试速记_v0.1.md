## 常见冷却液总览
TCS 侧常见水基单相冷却液：经处理的水、去离子水（DI water），或加入缓蚀剂/防冻剂的水—丙二醇（PG）或水—乙二醇（EG）混合液。具体选哪一种，不能只看导热好坏，而要同时满足冷板、快接头、泵、密封件和 CDU 的材料兼容性、水质规范、防冻要求与厂商保修条件。

| 类型 | 典型特点 | 更适合关注什么 | 注意点 |
|---|---|---|---|
| 经处理的水 / 低矿物质水 | 比热大、导热性能好、黏度低，泵耗较低 | 温和工况、密闭且水质管理到位的 TCS | 不能直接使用自来水 |
| 去离子水 DI water | 去除了多数离子和溶解盐，初始电导率低 | 对离子污染、结垢和电气风险控制要求高的系统 | 高纯 DI 水并不天然"永不腐蚀" |
| 水 + 缓蚀剂 / 生物控制剂 | 在水的热工性能与长期材料保护之间平衡 | 大多数长期运行水基闭式回路 | 必须按厂商指定浓度维护 |
| 水 + 丙二醇 PG | 提供防冻能力，毒性相对低 | 低温、寒冷地区、可能暴露于低温环境的系统 | 比水黏度更高、比热和导热通常更低，泵耗可能上升 |
| 水 + 乙二醇 EG | 防冻、热工性能通常优于 PG 水溶液 | 封闭、受控且防冻要求高的回路 | 有毒性，运维和泄漏管理要求更严 |
| 介电液 | 通常用于浸没式或特殊电子冷却架构 | 单相/两相浸没，而非典型冷板 TCS 主线 | 不是你当前冷板—CDU 主线重点 |

单相冷板液冷中，水、DI 水以及水—乙二醇/丙二醇溶液是常见选择；浸没式液冷更多用到绝缘介电液。

## 为什么不能直接用自来水
自来水中通常含有钙、镁、氯离子、硫酸根、金属离子、微生物和其他溶解物。长期流经 TCS 时可能带来：
```
离子 / 矿物质 / 微生物
   ↓
结垢、沉积、腐蚀、生物膜
   ↓
过滤器与冷板流道阻力上升
   ↓
支路压降增大、流量下降
   ↓
GPU / CPU 局部热风险上升
```
冷板内部流道、快速接头和精密阀件通常比普通建筑冷冻水管网更敏感，因此 TCS 需要更严格的液体质量、过滤、排气和监测。OCP 的 CDU 指导也把化学控制、过滤、排气与实时质量监测列为 TCS 的关键要求。

## 电导率是什么
电导率表示液体导电的容易程度，常用单位 μS/cm（微西门子每厘米，常写作 μS/cm）。电导率越高：液体中可移动离子通常越多；电导率越低：离子和溶解盐通常更少。电导率不是"水质全部"，但它是判断离子污染、混入异常物质或冷却液化学状态变化的一个重要在线指标。

粗略理解：
```
更多溶解盐 / 金属离子 / 杂质
   ↓
电导率升高
   ↓
水质可能偏离设计状态
```

## 去离子水为什么电导率重要（三点）
1. 判断离子污染和液体劣化：DI 水刚制备时电导率很低，但系统内循环后会不断与金属、密封件、空气、补液、残余颗粒和腐蚀产物接触，吸收离子或溶解物。
```
初始 DI 水 → 电导率低
长期运行 → 混入离子 / 腐蚀产物 / 补液杂质 → 电导率上升 → 需要分析水质、材料状态或污染来源
```
持续上升的电导率并不自动等于"马上泄漏"，但它是应触发取样分析、检查补液、过滤、腐蚀和材料兼容性的信号。大型关键闭式水系统的水处理指导也建议持续或定期监测电导率、pH、浊度和腐蚀状态，并在电导率上升时分析原因。

2. 降低结垢、沉积与腐蚀风险：去离子过程能减少会形成水垢或参与腐蚀反应的矿物质、盐和离子，因此 DI 水常用于需要较高纯度的液冷回路（含冷板、窄流道、铜/铝/不锈钢等多种材料）。但要纠正一个常见误解：
```
DI 水电导率低，不代表它天然不会腐蚀。
```
高纯水离子很少，但可能因"化学活性"更强而从金属或材料中溶出离子，使自身电导率随运行上升，并改变回路腐蚀风险。因此 TCS 不能只追求"越纯越好"，而需要将 DI 水、缓蚀剂、材料兼容性、pH、过滤、排气和厂商规范作为整体管理。资料也指出，过低电导率的水在某些系统中反而可能具有腐蚀性，需结合材料和化学处理判断。

3. 影响漏液后的电气风险：若发生泄漏，低电导率液体相对不易导电，可能降低短路、漏电和电化学腐蚀风险；但这只是降低风险，并不意味着"DI 水漏到服务器上就安全"。
```
DI 水泄漏 → 接触金属、灰尘、PCB 表面残留物 → 吸收离子 → 电导率可能迅速上升 → 仍可能造成电气和腐蚀风险
```
真正的安全措施仍是：防漏设计；快速接头与密封管理；漏液检测；分区隔离；受控停机或降载；按厂商要求选择液体和维护水质。不能把"去离子水不导电"当成液冷泄漏风险可以忽略的理由。

## 不要死背一个统一电导率数值
不同服务器和液冷系统规范差异很大。例如 IBM 某水冷系统规范要求在 20–25°C 下电导率不高于 10 μS/cm，但这只是特定设备规范，不应直接套用到所有 CDU、冷板或数据中心项目。

面试中最稳的说法：
TCS 冷却液的电导率、pH、离子含量、颗粒物、微生物控制和材料兼容性必须遵循服务器、冷板、CDU 与冷却液厂商的共同规范。电导率是反映离子污染和液体状态变化的重要在线指标；如果运行中持续上升，应结合补液记录、过滤器状态、腐蚀产物和水质取样分析原因，而不是只看单一读数。

## 记忆口诀
- 为什么不用自来水？→ 杂质、矿物、氯离子、微生物可能带来结垢、腐蚀和堵塞。
- 为什么用 DI 水？→ 初始离子少，便于控制水质并减少结垢/离子污染风险。
- 为什么还要看电导率？→ 看冷却液是否在吸收离子、被污染或偏离设计状态。
- 为什么 DI 水也不能掉以轻心？→ 它会吸收离子，可能改变腐蚀风险；泄漏后也可能很快变得导电。
- 最终原则？→ 不迷信"纯水"，严格按 OEM / CDU / 冷板共同规范做液体配方、过滤、监测和维护。

## 笔记版自测清单
- 六类冷却液：经处理水 / DI 水 / 水+缓蚀剂 / 水+PG / 水+EG / 介电液（介电液属浸没，非冷板主线）。
- 选型依据：材料兼容性、水质规范、防冻要求、厂商保修；不是只看导热。
- 自来水危害链：杂质→结垢/腐蚀/生物膜→阻力↑→压降↑→流量↓→热风险↑。
- 电导率：单位 μS/cm；高=离子多；是判断离子污染/液体劣化的重要在线指标，但不是水质全部。
- DI 水三点：①持续上升电导率是取样/查补液/查腐蚀的信号（≠马上泄漏）；②低电导率不代表不腐蚀（高纯水可能溶出离子，过低电导率可能反而有腐蚀性）；③泄漏后电导率可能迅速上升，不能当安全理由。
- 不背统一数值：IBM 10 μS/cm 是特定规范示例；面试说"按厂商共同规范"。
