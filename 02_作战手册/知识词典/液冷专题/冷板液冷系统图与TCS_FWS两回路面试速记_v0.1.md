> 定位：数据中心冷却主线 · 冷板液冷系统图专题。
> 回链：承接 `高密度承压与冷板CDU液冷入门面试速记_v0.1.md` 模块B（系统边界/术语/CDU 六功能），本篇把"TCS↔CDU换热器↔FWS"这张图展开成"左框 TCS / 右框 FWS / 中间 CDU"两回路讲解，并解决命名（一次/二次侧 vs TCS/FWS）。
> 与 `液冷路线全景面试速记_v0.1.md`（五路线分层）平行，不重复。本篇不进冷板流道、TIM、封装。

## 目标
今天的目标不是背更多术语，而是：不看资料，能画出冷板液冷总系统图，并把两条回路讲清楚。冷板液冷行业参考文档的标准表达：CPU/GPU → 冷板 → 技术冷却回路（TCS） → CDU → 设施水系统（FWS） → 冷源 → 室外。

## 一张总系统图（文字版）
先画一条纵向热量路径，中间是 CDU，左右各一套回路：
```
CPU / GPU
   ↓
冷板 Cold Plate
   ↓
服务器/机柜歧管
   ↓
技术冷却液回路 TCS
   ↓
CDU （冷却液分配单元）
   ↓
设施水供回水 FWS / FWR
   ↓
冷源与室外排热
（冷水机 / 干冷器 / 冷却塔 / 自然冷却）
   ↓
室外环境
```

完整热量路径：
```
CPU / GPU 产生热量
   ↓
冷板直接贴在芯片附近吸热
   ↓
技术冷却液在冷板中升温
   ↓
技术冷却液流到 CDU 换热器一侧
   ↓
设施水在换热器另一侧吸收这部分热量
   ↓
设施水把热量带到冷水机、干冷器、冷却塔等冷源/排热设备
   ↓
最终通过冷凝、蒸发或干冷排到室外空气/环境
```
关键：CPU/GPU 的主要热量不再通过机房空气长途搬运，而是通过冷板和技术冷却液在服务器近端被截获，再由设施水系统送往冷源。

## 左边：技术冷却液侧（TCS）
图画在左半边，闭环，标"服务器侧 / IT 设备侧"。

典型组成：
```
CPU / GPU 冷板
   ↕ （冷却液通道）
服务器内软管和接头
   ↕
机柜歧管（供液/回液集管）
   ↕
CDU 内的二次侧泵、过滤器、膨胀/液位控制
   ↕
技术冷却液（可能是水或专用冷却液）
```
主要任务：把 CPU、GPU 等高热流密度部件产生的热量，从芯片附近用冷板和技术冷却液带到 CDU。

口述话术：技术冷却液回路是在服务器这一侧贴身服务芯片的液体回路，通常包括冷板、服务器内软管、机柜歧管以及 CDU 的二次侧泵和监测。它的工作是把 CPU/GPU 的热量尽量靠近热源捕获，并用液体带到 CDU，不负责直接排到室外。

## 右边：设施水侧（FWS / FWR）
图画在右半边，更大的闭环，标"数据中心设施侧"。

典型组成：
```
数据中心设施水管网（FWS / FWR）
   ↕
设施水泵
   ↕
CDU 换热器另一侧
   ↕
冷水机组 / 干冷器 / 冷却塔 / 经济器（自然冷却设备）
   ↕
室外空气 / 环境
```
主要任务：把 CDU 从技术冷却液接收到的那部分热量，继续通过设施水系统送往冷源和排热设备，最终排到室外。

口述话术：设施水侧可以看成数据中心原有的水系统：冷冻水或温水、设施水泵、CDU 换热器另一侧、冷机、干冷器或冷却塔等冷源。CDU 只是把服务器侧液冷回路接到这套设施水系统上，实现热量从 TCS 转移到 FWS，最终仍由设施水系统和冷源排热。

### 设施水侧的主要设备
| 设备/管路 | 主要作用 | 你要如何理解 |
|---|---|---|
| FWS / FWR 主管 | 把设施水送到 CDU，再把带热设施水送回冷源 | 液冷系统的"大动脉" |
| 设施水泵 | 推动设施水在 CDU 与冷源之间循环 | 类似传统冷冻水泵，克服 CDU、管路、阀门和冷源阻力 |
| CDU 设施水侧换热器 | 从 TCS 接收热量并交给 FWS | 两侧液体通常不直接混合 |
| 调节阀 / 隔离阀 / 旁通阀 | 调节 FWS 流量、隔离检修设备、支持切换和混水 | 设施水侧的"交通调度器" |
| 冷水机组 | 通过蒸汽压缩制冷把 FWS 热量转移给冷却水侧 | 高温天气或低水温需求下的主要冷源 |
| 冷却水泵 | 将冷水机冷凝器热量送到冷却塔 | 只出现在水冷冷水机组路线中 |
| 冷却塔 | 通过蒸发向室外空气排出冷凝热 | 水冷冷机的最终排热设备之一 |
| 干冷器 | 通过室外空气与盘管换热排热，不以蒸发为主 | 较高 FWS 温度、较低室外干球温度时有利 |
| 板式换热器 | 在自然冷却模式下让设施水与冷却侧/室外侧间接换热 | 可能减少或绕开压缩机制冷 |
| 水处理、过滤、补水设备 | 控制腐蚀、结垢、颗粒物和水质 | 保护泵、阀门、换热器、冷机和管网 |
| 传感器与控制系统 | 监测温度、流量、压差、阀位、泵状态 | 支持冷源切换、故障诊断和节能控制 |

FWS 连接 CDU、泵、冷机、冷却塔、干冷器及热回收等设施级设备；具体项目可能用冷冻水，也可能用较高温度的设施水接入干冷器或自然冷却系统。

## 两个回路的关系（一定要画）
左右两个框，中间一个 CDU：
```
左框：技术冷却液侧 TCS（服务器侧）
  ┌────────────────────────┐
  │ 冷板、软管、机柜歧管   │
  │ CDU 二次侧泵、过滤     │
  └────────────────────────┘

           技术冷却液把热量带到 CDU
                     ↓

          CDU 板式换热器（热量从左侧液体传给右侧水）

                     ↑
       设施水把热量带到冷源和室外
  ┌────────────────────────┐
  │ 设施水管网、设施水泵   │
  │ 冷水机、干冷器、冷却塔 │
  └────────────────────────┘
右框：设施水侧 FWS / FWR（数据中心设施侧）
```
一句话总结：冷板液冷系统里，热量在左边 TCS 被捕获，在 CDU 换热器里跨到右边 FWS，在右边设施水系统里被排出。两边液体通常不直接混合。

## 为什么不用"一次侧/二次侧"来讲
不同厂商、文档对"一次侧、二次侧"的指代可能不一样：有的把设施水叫"一次侧"、把技术冷却液叫"二次侧"；有的相反；有的在不同设备层面有不同定义。但大家都普遍接受两层清晰的工程语言：技术冷却液侧（TCS）= 服务器/IT 设备近端的冷板、歧管和 CDU IT 回路；设施水侧（FWS/FWR）= 数据中心原有的冷冻水/温水、泵、冷机/塔/干冷器等设施。面试中说"TCS 和 FWS 两个回路，中间由 CDU 通过换热器连接"，比说"一次侧、二次侧"更稳、更少争议。

## 笔记版自测清单
- 不看资料能画出：CPU/GPU → 冷板 → 服务器/机柜歧管 → TCS → CDU → FWS/FWR → 冷源 → 室外。
- 完整热量路径能口述：冷板吸热 → 技术冷却液升温 → 到 CDU 换热器一侧 → 设施水另一侧吸热 → 冷源/排热设备 → 室外。
- 左框 TCS：冷板、软管、机柜歧管、CDU 二次侧泵/过滤/液位控制；任务=近端捕获芯片热量带到 CDU。
- 右框 FWS：设施水管网、设施水泵、CDU 换热器另一侧、冷机/干冷器/冷却塔/经济器；任务=把热量送到冷源排室外。
- 中间 CDU：板式换热器把热量从 TCS 液体传给 FWS 水，两边液体不直接混合。
- 命名：优先说 TCS/FWS，不说"一次侧/二次侧"（厂商叫法不一致）。

## 口述复述（今日练习）
技术冷却液回路是服务器侧的液体回路，冷板贴身吸收 CPU/GPU 的热量，技术冷却液把热量带到 CDU 换热器一侧；设施水回路是数据中心侧的水系统，在换热器另一侧吸收热量，再由冷机、干冷器或冷却塔把热量排到室外。两个回路在 CDU 换热器处交换热量但不直接混水，因此 TCS 与 FWS 可各自独立控制压力、水质和温度。我一般用 TCS 和 FWS 来命名这两层回路，而不是"一次侧、二次侧"，因为不同厂商对后者的叫法不一致。

## TCS vs FWS 逐维度对照
| 对比 | TCS 技术冷却液侧 | FWS 设施水侧 |
|---|---|---|
| 服务对象 | CPU/GPU 冷板、服务器、机柜歧管 | CDU、冷源、室外排热设备 |
| 主要任务 | 靠近芯片吸热 | 将热送至冷源并排出室外 |
| 典型设备 | 冷板、软管、快接头、机柜歧管、CDU TCS 泵 | FWS 管网、设施水泵、冷机、干冷器、冷却塔、板换 |
| 水质要求 | 通常更严格，保护冷板与 IT 设备附近回路 | 取决于设施系统，但仍需水处理和过滤 |
| 温度控制重点 | 芯片热安全、露点、冷板换热能力 | 冷源效率、自然冷却机会、室外工况 |
| 风险重点 | 冷板堵塞、快接头漏液、支路流量不足 | 泵故障、冷机/塔/干冷器能力不足、公共主管单点故障 |

最该记住的一句话：TCS 负责在服务器近端把 CPU/GPU 的热量收集到 CDU；FWS 负责通过设施水泵、管网和冷源设备把 CDU 接收的热量持续输送并最终排到室外。CDU 是两套回路的隔离换热接口。

## 设施水侧的可靠性（不能只看 CDU）
设施水侧也必须做完整可靠性检查，不能只看 CDU 正不正常：
```
CDU 正常
但 FWS 泵故障
→ CDU 换热能力下降
→ TCS 供液温度升高
→ GPU 温度风险上升

CDU 正常
但冷机 / 干冷器 / 冷却塔能力不足
→ FWS 温度升高
→ CDU 无法继续排热
→ 整个液冷链受限
```
检查 FWS 可靠性要看：
- 设施水泵是否有 N+1 或备用切换；
- CDU 是否有可隔离的 FWS 支路；
- FWS 主管是否存在单点故障；
- 冷机、干冷器、冷却塔是否有足够容量与冗余；
- 阀门、供电、控制器、通信是否会成为公共单点；
- 冷源切换到自然冷却或机械制冷时是否可正常联锁。

此清单与 `液冷可靠性与故障域控制面试速记_v0.1.md` 可靠性树的公共依赖检查（主管/控制器/电源/隔离/检修）同一门语言，只是落到 FWS 侧逐项。
