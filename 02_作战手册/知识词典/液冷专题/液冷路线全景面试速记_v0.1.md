# 液冷路线全景面试速记_v0.1

> 定位：数据中心冷却主线 · 高密度液冷路线专题（接 `高密度承压与冷板CDU液冷入门面试速记_v0.1.md`）。
> 回链：与 `数据中心冷却面试速记`、`PUE理解与冷却能耗链面试速记`、`CRAH风机与冷冻水泵变频节能面试速记`、`设定值优化面试速记`、`冷冻水冷却水系统与水泵控制面试速记` 平行，不重复。
> 视角：五条路线应按"热量在哪一层被液体接走"理解，而不是全部都叫"液冷"。强化空气冷却是空气侧方案；RDHx 是机柜后部的空气—液体换热；冷板和浸没才是液体更直接接近发热器件的路线。主线 = 冷板式直接液冷（D2C/DLC），浸没限制在概念层。

## 核心视角：路线地图
```
离芯片越远                                      离芯片越近
──────────────────────────────────────────────────────

强化空气冷却
机房空气 / 冷热通道 / CRAH
        ↓
后门换热器 RDHx
服务器热排风 → 机柜后门水盘管
        ↓
冷板式直接液冷 D2C / DLC
CPU / GPU → 冷板内冷却液
        ↓
单相浸没
整台服务器 → 绝缘液体
        ↓
两相浸没
发热部件附近 → 绝缘工质沸腾吸热
```

主线取舍：
```
强化空气冷却 → RDHx（知道）→ 冷板液冷（重点）
                           ↘ 单相浸没（理解）
                            ↘ 两相浸没（知道概念）
```

## 五条路线对照
| 路线 | 热量首先被谁带走 | 液体在哪一层接热 | 你要掌握到什么程度 |
|---|---|---|---|
| 强化空气冷却 | 服务器风扇推动的空气 | 不直接在 IT 设备近端接热，仍由 CRAH/CRAC 处理机房空气 | 理解适用边界 |
| RDHx 后门换热器 | 服务器先把热量排到空气中 | 机柜后门盘管从服务器热排风中取热 | 知道位置、作用、与冷板区别 |
| 冷板式直接液冷 | 冷板中的技术冷却液 | CPU/GPU 等芯片附近 | 重点掌握 |
| 单相浸没 | 整机周围的绝缘液 | 服务器/部件外表面直接与液体接触 | 理解原理、优缺点 |
| 两相浸没 | 绝缘工质的相变 | 发热部件附近发生沸腾吸热 | 只会解释概念 |

ASHRAE 的 AI 数据中心框架将 RDHx 视为降低机房热负荷的混合式方案，将冷板液冷和浸没式视为支持高密度 AI 机柜的液冷或液体辅助架构。

## 1. 强化空气冷却（不是液冷）
把你已学过的空气侧能力做得更好：
```
冷空气 → 冷通道 → 服务器前部 → 服务器风扇与散热器 → 热通道 → CRAH/CRAC → 冷冻水或制冷剂
```
手段：冷热通道封闭、盲板、线缆孔封堵，减少热回流和冷风旁通；优化服务器进风与送风路径，提高有效送风比例；CRAH 风机按需变频而非长期全速；行级/近端/机柜级空气冷却缩短输送路径；在进风温湿度与冗余允许时提高供风或回风温度设定，减轻冷机负担。

适用边界：仍适用于大量普通机柜和存量数据中心。但高密度 AI/HPC 的问题在于，为靠空气带走更多热量，风量、压降、风机功耗与局部气流组织难度都会上升（与 `高密度承压与冷板CDU液冷入门面试速记` 模块A 的 Q=ρV̇c_pΔT、P∝n³ 一致）。

## 2. 后门换热器 RDHx（知道）
装在机柜后门上的大号水冷散热器：
```
冷通道 → 服务器前部进冷空气 → 服务器风扇/散热器 → 服务器后部排热空气 → RDHx 后门盘管 → 水带走热量 → 设施水/冷源
```
关键点：服务器内部仍主要由风扇和空气带走热量；热空气离开服务器后，在进入机房热通道前穿过后门水盘管；盘管将热量从空气传给水，减少热空气进入机房的量；水始终在后门盘管内，通常不接触服务器电子元件。RDHx 通常安装或替换在机柜后门，服务器热排风经过内部液冷盘管后，将热量传递给液体，因而减少进入机房的热量。

与冷板液冷的根本区别：
| 对比点 | RDHx | 冷板直接液冷 |
|---|---|---|
| 液体接热位置 | 机柜后部的热排风 | CPU/GPU 等芯片附近 |
| 服务器内部主要输热介质 | 空气 | 技术冷却液承担主要芯片热量 |
| 是否依赖服务器风扇 | 是，仍高度依赖 | 仍可能需要，但主要芯片热量不再完全依赖空气 |
| 典型作用 | 机柜级截获热排风、降低机房热负荷 | 直接处理高热流芯片 |
| 当前学习要求 | 理解位置与作用 | 重点掌握系统链路 |

## 3. 冷板式直接液冷：主线（重点）
```
CPU / GPU → 冷板 → 服务器支路软管 → 机柜歧管 → CDU → 设施水 FWS → 冷水机/干冷器/冷却塔 → 室外环境
```
冷板贴近 CPU、GPU 或其他高热流密度芯片，技术冷却液流经冷板并带走主要热量，再通过机柜歧管和 CDU 交给设施水系统和数据中心冷源（CDU 六功能、TCS↔FWS 双回路边界见 `高密度承压与冷板CDU液冷入门面试速记` 模块B）。

冷板通常不覆盖全部部件，以下仍需要空气侧：内存 DIMM；电源 PSU；网卡/NIC、DPU；SSD、存储部件；主板其他芯片与电路；某些未纳入液冷覆盖范围的加速卡或附件。

准确表达：冷板液冷不是取消空气冷却，而是将 CPU/GPU 等主要热源的热量提前在服务器近端由液体带走；未被冷板覆盖的部件仍依赖服务器风扇和 CRAH/CRAC，因此典型架构是冷板液冷加剩余空气冷却的风液混合系统。

## 4. 单相浸没式液冷（理解）
整台服务器或板卡浸在不导电液体里，液体本身不沸腾：
```
服务器/主板/CPU/GPU → 整体浸入绝缘冷却液 → 液体吸收热量但不发生相变 → 泵送循环/换热器 → 设施水/冷源 → 室外排热
```
优点：大量部件都可与绝缘液体直接换热，减少对机柜气流组织的依赖；服务器风机可能减少甚至取消；适合极高热密度或空气侧空间受限场景；不再以冷热通道和机柜进风为主要散热矛盾。
工程代价：维护方式改变（不能像普通服务器直接抽出插拔检修）；液体、密封材料、线缆、连接件和电子元件需长期兼容；需解决补充、过滤、转运、泄漏和回收；服务器、机柜、运维工具和人员规范通常要适配。核心是整服务器浸入绝缘液体，吸热后经换热设备冷却；适合高密度，但运维、设备兼容性和液体管理是主要工程权衡。

## 5. 两相浸没式液冷（知道概念）
系统形态与单相相似，但机理不同：
```
高热流芯片 → 绝缘液在器件附近沸腾、汽化 → 蒸汽上升 → 顶部冷凝器 → 冷凝成液体 → 回流到服务器附近
```
相变时，液体通过汽化潜热带走大量热量，热管理潜力很高。只需记住：单相浸没靠液体升温后循环带热；两相浸没靠绝缘液在热源附近沸腾吸热、在冷凝器处冷凝回流。两相方案不进入当前主学习线，涉及工质、密封、沸腾稳定性、冷凝器与材料兼容等更细工程问题，不学沸腾换热系数或工质选型。

## 浸没式怎么排热（后半段与冷板同构）
浸没式同样需要把热量排到室外，只是"服务器内部第一段热量路径"变了。

单相浸没（绝缘液始终保持液态、不沸腾）：
```
CPU/GPU/内存/主板等 → 整机浸在绝缘液中 → 绝缘液吸热、温度升高 → 泵送循环 → 液—液换热器/CDU → FWS 设施水 → 冷机/干冷器/冷却塔 → 室外环境
```
单相浸没与冷板液冷的后半段其实非常像：冷板液冷是 冷板 → TCS → CDU → FWS → 室外；单相浸没是 浸没槽绝缘液 → 换热器/CDU → FWS → 室外。区别只是冷板液冷在 CPU/GPU 的冷板中吸热，而单相浸没由整槽绝缘液直接包围服务器部件吸热。

两相浸没（绝缘液在热源附近沸腾汽化）：
```
CPU/GPU 等热源 → 槽内低沸点绝缘液吸热并汽化 → 蒸汽上升到槽顶 → 槽顶部冷凝器盘管 → 蒸汽被冷凝成液体 → 液体滴回浸没槽
```
冷凝器盘管内部通常流的是设施水或另一个冷却水回路：芯片热量 → 绝缘液汽化 → 蒸汽 → 顶部冷凝器外壁 → 盘管内的 FWS/冷却水 → 冷源与室外环境。两相浸没的关键不是"热量消失"，而是：芯片热量先变成工质汽化潜热，再在顶部冷凝器传给设施水，最后仍由冷机、干冷器或冷却塔排到室外。

三种液冷路线放一起：
```
冷板液冷：CPU/GPU → 冷板 → TCS → CDU → FWS → 室外
单相浸没：服务器整体 → 绝缘液升温 → 泵/换热器 → FWS → 室外
两相浸没：服务器整体 → 绝缘液汽化 → 顶部冷凝器 → FWS → 室外
```
最重要的统一认识：无论冷板还是浸没，液体只是在更靠近芯片的位置接走热量；最终都必须经过换热器、设施水、冷机/干冷器/冷却塔等设施侧系统，把热量排到室外。

## 今日必须分清的三个误区
1. RDHx 就是冷板液冷——不对。RDHx 是机柜后部空气—水换热；冷板液冷是芯片附近液体—固体换热。
2. 冷板液冷后不需要 CRAH——不对。典型冷板系统仍要处理未覆盖部件的残余热量，所以常与 CRAH/CRAC 和冷热通道并存。
3. 液冷等于全部服务器泡在液体中——不对。冷板式直接液冷是当前最应重点理解的路线；浸没只是另一类液冷方案。公开资料通常将直接芯片冷板与浸没式列为两类主要的直接液冷方式。

## 笔记版自测清单
- 视角：路线 = 热量在哪一层被液体接走；不是所有都叫"液冷"。
- 五路线顺序（离芯片由远及近）：强化空气冷却 → RDHx → 冷板 D2C → 单相浸没 → 两相浸没。
- 主线取舍：冷板（重点）/ RDHx（知道）/ 单相浸没（理解）/ 两相浸没（概念）。
- RDHx：后门水盘管截获热排风，水不进服务器内部，仍高度依赖服务器风扇。
- 冷板：仍留 DIMM/PSU/NIC/SSD/主板 等空气侧残余负荷，风液混合长期存在。
- 单/两相浸没差异：循环升温带热 vs 沸腾汽化+冷凝回流；两相不进主线。

## 60秒面试版
数据中心高密度冷却路线可以按液体在哪里接走热量来区分。强化空气冷却仍通过 CRAH/CRAC 和气流组织排热，适合大量普通机柜；RDHx 安装在机柜后门，通过水盘管截获服务器热排风，仍属于服务器内部以空气输热为主的近端方案。冷板式直接液冷则把冷却液送到贴近 CPU/GPU 的冷板，是我重点关注的路线，热量经服务器支路、机柜歧管和 CDU 交给设施水系统。但冷板通常不覆盖内存、电源和网卡等部件，所以仍需要空气侧处理残余热量，典型架构是风液混合。浸没式液冷则将整机浸入绝缘液体，单相依靠液体循环升温带热，两相依靠工质沸腾和冷凝回流；我目前理解其系统概念和工程权衡，不作为深入方向。
