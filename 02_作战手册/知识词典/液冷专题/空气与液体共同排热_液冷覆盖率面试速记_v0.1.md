# 空气与液体共同排热_液冷覆盖率面试速记_v0.1

> 定位：数据中心冷却主线 · 冷板液冷"风液混合"量化收口。
> 回链：承接 `液冷路线全景面试速记_v0.1.md`（冷板为主线的风液混合）、`高密度承压与冷板CDU液冷入门面试速记_v0.1.md`（模块A 风液混合不是过渡失败）、`CDU六功能详解面试速记_v0.1.md`（TCS/FWS 路径）。
> 本篇核心：冷板液冷通常不是替代空气侧，而是把热量按部件重新分配给液体和空气两条路径，并用"液冷覆盖率"量化这个分配。

## 核心逻辑（收口）
冷板液冷通常不是替代空气侧，而是把热量按部件重新分配给液体和空气两条路径：CPU/GPU 等高热部件由冷板近端带走主要热量；VRM、内存、硬盘、网卡、电源等未被液冷覆盖的部件仍需要服务器风扇与机房空气侧冷却。

## 液冷覆盖率（工作定义）
建议把"液冷覆盖率"作为一个便于理解的工作定义，而不是声称它是所有厂商统一采用的单一标准指标：

η_liquid = Q_liquid / Q_IT,total

其中：
- Q_liquid：由冷板—TCS—CDU—FWS 路径带走的热量；
- Q_IT,total：服务器或机柜的总 IT 热量；
- 1 − η_liquid：仍留给服务器风扇、冷热通道与 CRAH/CRAC 空气侧处理的剩余比例。

## 一台服务器的两条热量路径
```
总 IT 热量
    │
    ├── CPU / GPU / AI 加速器主要热量
    │        ↓
    │     冷板
    │        ↓
    │     TCS 技术冷却液
    │        ↓
    │     CDU
    │        ↓
    │     FWS 设施水 → 冷源 → 室外
    │
    └── 内存 / 电源 / 网卡 / SSD / 主板等残余热量
             ↓
          服务器风扇
             ↓
          冷通道 → 热通道
             ↓
          CRAH / CRAC
             ↓
          冷冻水/制冷剂 → 冷源 → 室外
```

## 举例理解（示例，数值为典型示意）
设一台 2U 服务器总 IT 功耗 Q_IT,total = 2000 W：
- 液冷路径：CPU/GPU 及其周边主要热量约 1600 W 由冷板 → TCS → CDU → FWS 带走，即 Q_liquid = 1600 W，η_liquid = 1600/2000 = 0.8。
- 空气侧路径：VRM、内存、硬盘、网卡、电源等残余热量约 400 W 由服务器风扇排入冷通道/热通道，再由 CRAH/CRAC 经冷冻水或制冷剂排到冷源与室外，即 1 − η_liquid = 0.2。

注意：η_liquid 的典型值随服务器设计、冷板覆盖范围和负载分布而变，并非厂商统一标准；面试中用它说明"热量按部件在液体与空气两条路径间分配"即可，不要当成固定数值指标。

## 笔记版自测清单
- 收口表达：冷板液冷不是替代空气侧，而是按部件把热量分给液体和空气两条路径。
- 公式：η_liquid = Q_liquid / Q_IT,total；1 − η_liquid = 空气侧剩余比例。
- 液体路径：CPU/GPU/AI 加速器 → 冷板 → TCS → CDU → FWS → 冷源 → 室外。
- 空气路径：内存/电源/网卡/SSD/主板 → 服务器风扇 → 冷热通道 → CRAH/CRAC → 冷冻水/制冷剂 → 冷源 → 室外。
- 举例能算：2000 W 中 1600 W 液冷（η=0.8）、400 W 空气侧；并说明是示意值，非统一标准。
