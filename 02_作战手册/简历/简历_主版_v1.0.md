### 项目：面向传感数据缺失的个体热舒适预测鲁棒性研究（硕士课题 · 英文论文在投）

1. **问题与职责**：面向建筑环境传感数据缺失的实际应用场景，研究热舒适预测模型在温度 / 湿度 / 风速等传感数据缺失下的鲁棒性，以及模型对传感器输入的依赖程度，负责实验设计与结果分析
2. **实验与方法**：基于 Python + XGBoost 构建端到端实验流程，设计"完整基线 / 部署端缺失 / 缺失感知训练 / 安全检查"四组对照场景（内部实验编号 A0/A1/A2/A3），系统比较 5 种缺失处理策略，在 10%–50% 缺失率与多次随机重复下验证稳定性；训练与测试严格分离
   > 投递版通俗口径（已用于 A/B）："设计完整数据、测试端缺失及缺失感知训练等多场景对照实验，比较 5 种缺失处理策略，并在 10%–50% 缺失率及多次随机重复下验证结果稳定性（训练与测试严格分离）"——内部编号与"安全检查"留给面试展开。
3. **结果**：受控缺失条件下，完整数据训练模型在缺失输入下整体性能退化（macro-F1 由约 0.63 降至约 0.61 @50% 缺失），缺失感知训练可实现部分恢复，不同缺失处理策略存在鲁棒性权衡
4. **价值与成果**：为降低传感器依赖的后续部署方案提供实验依据（属探索可行性，非已实现部署）；英文论文在投

2. **控制与工况运行**：根据分区人数与人均新风量完成新风需求及阀门开度计算，设置传统固定新风控制（CCS）与占用驱动控制（OBCS）工况，基于既有 EnergyPlus 模型完成 CCS/OBCS 工况仿真运行与能耗结果整理；基于既有 CFD 模型完成对比工况计算及温度、风速、湿度、CO₂ 结果后处理
