# 自我介绍 · 空调制冷版（90 秒，派生自母版）

> 用途：投 HVAC 系统 / 制冷 / 暖通研发 / 空调设备应用岗位。前 80% 同母版，结尾换"HVAC 匹配"段。
> 派生规则见 `自我介绍_派生规则.md` 第 5 条。

面试官好，我是某用户，某高校人工环境工程硕士，求职方向为数据中心冷却 / 热管理与空调制冷 / HVAC 系统两类岗位。

我的技术底座覆盖制冷循环、空气侧处理、水系统泵阀、VRF / DOAS、负荷计算与控制能效，能把暖通系统基础、控制与能效优化思维，以及 Python 数据分析和机器学习研究能力结合起来。

项目上，我的硕士课题做"传感数据缺失下的个体热舒适预测"——研究传感器缺了之后模型会差多少、不同补救办法能不能救回、哪些传感器缺不得；另一篇已发表 SCI 论文做"占用驱动的 VRF + DOAS 分区新风优化控制"——这是合作项目，团队负责 CNN 人数识别前端，我负责后端：把分区人数转化为新风需求与 DOAS 阀开度，并基于既有 EnergyPlus / CFD 模型运行工况、整理能耗与室内环境结果，研究案例显示总 HVAC 用电降 X%、平均 PPD 从 14.3% 降到 7.2%。

我还有一段施工员实习，参与上海某商业综合体中心商业改造项目的集中式中央空调施工检查，现场接触水冷冷水机组、冷冻/冷却水泵、冷却塔、AHU/PAU/FCU 以及风管水管等设备与部件，结合施工图核对设备、管线与现场布置；让我对"从冷机、水泵、冷却塔到空气处理末端再到风管送风"的完整系统有了直观认识，也理解了改造现场的空间、标高与多专业协调约束。

我希望在贵司把暖通系统理解、控制能效优化与数据分析能力，落地到空调制冷 / HVAC 系统的设备与系统工程应用上——项目二完整展示 VRF + DOAS、分区新风、能耗与舒适 / IAQ 权衡，项目一对应 HVAC 控制前端的传感数据可靠性与计算负担问题。
