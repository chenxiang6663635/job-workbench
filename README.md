| 层 | 核心问题 | 当前最该做的事 | 对应目录 |

## 关键纪律（防止"面试稿写太多"）

- 简历每个动词都经得起 5–10 分钟追问，动词由贡献矩阵决定，不把"参与"一律升级为"负责"。
- 项目一"轻量化"= **探索降低传感器依赖的可能性**，不写"实现轻量化部署"。
- 项目二结果是 EnergyPlus/CFD 仿真 + 单一阅览室案例；X% 须能讲清基准、工况、怎么算、哪张图、为什么。
- 自我评价 → Profile：只写专业身份 + 技术底盘 + 项目能力 + 求职方向，不写性格。
- 三套简历 = 1 Master + 2 派生，只改四处（求职方向 / Profile / 技能顺序 / 项目表述），**项目事实不变**。
- SCI 成果与项目二建立显式关联，不当作孤立"成果栏"。
- 60 题 × 70% 脱稿 远胜 180 题 × 看过答案；行为面建故事库，不做"20 题 × 20 故事"。
