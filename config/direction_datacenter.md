# 方向配置：数据中心冷却 / 热管理

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**关键词三级词典**与**方向契合锚点表**。

修改本文件即改变评分标准，无需改动任何 Python 代码。

---

## 一、技术匹配关键词词典

比对 JD 文本（含岗位职责与任职要求）。命中 Primary 计 3 分/项，命中 Secondary 计 1.5 分/项，技术匹配上限 30 分。

### Primary（3 分/项）—— 核心技术底盘

制冷循环、蒸气压缩、制冷原理、COP、EER、蒸发器、冷凝器、压缩机、节流
传热、换热、传热系数、对流、导热、辐射
流体、管网水力、水力平衡、阻力、压降、流量
风水系统、冷冻水、冷却水、冷却水系统、冷冻水系统
HVAC、暖通、空调系统、空气处理、AHU、PAU、FCU
控制策略、PID、自动控制、控制逻辑、闭环控制、群控

### Secondary（1.5 分/项）—— 具备实操，支撑但要谨慎表述

EnergyPlus、CFD、Fluent、能耗模拟、建筑能耗仿真
Python、数据分析、Pandas、机器学习、数据驱动
现场施工、施工协调、施工组织、多专业交叉、深化设计
焓湿图、空气状态、露点、相对湿度、显热、潜热
变频、VFD、水泵变频、风机变频
DOAS、VRF、新风机组、热回收

### Weak（登记不扣分，触发风险提示）—— 知识性了解，无工程交付经历

液冷工程交付、冷板、CDU 工程实施、TCS 系统实施
数据中心运维、机房运维、7×24 值守、SLA
浸没式液冷、冷板液冷交付、歧管、快接头
BA 系统实施、楼宇自控实施

> 命中 Weak 项时：不扣分，但必须在解析卡「命中 Weak」登记，并在结论中给出诚实桥梁话术建议——只能指向真实可迁移能力，不得生成听起来像经历的表述。

## 二、方向契合锚点表（30 分）

锚定「冷却系统与热管理」主线。按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 数据中心冷却 / 热管理 | 25–30 | 主线岗位，直接对口 |
| IDC 基础设施 / 机房暖通 | 22–28 | 高度相关，需确认是否偏运维 |
| 液冷产品研发 / 热设计 | 20–26 | 相关，但 Weak 项大概率被追问 |
| 储能热管理 / 电池热管理 | 18–24 | 热管理能力可迁移 |
| 建筑能源管理 / 节能优化 | 12–18 | 部分相关 |
| 非热方向 | 0–8 | 基本不匹配 |

判定提示：岗位名称与职责不一致时，以职责为准并在解析卡说明判断依据。
