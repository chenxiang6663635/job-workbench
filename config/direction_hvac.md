# 方向配置：空调制冷 / HVAC 优化

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**关键词三级词典**与**方向契合锚点表**。

修改本文件即改变评分标准，无需改动任何 Python 代码。

---

## 一、技术匹配关键词词典

比对 JD 文本（含岗位职责与任职要求）。命中 Primary 计 3 分/项，命中 Secondary 计 1.5 分/项，技术匹配上限 30 分。

### Primary（3 分/项）—— 核心技术底盘

制冷循环、蒸气压缩、制冷原理、COP、EER、蒸发器、冷凝器、压缩机、节流
传热、换热、传热系数、对流、导热、辐射
流体、管网水力、水力平衡、阻力、压降、流量

HVAC、暖通、空调系统、空气处理、AHU、PAU、FCU
控制策略、PID、自动控制、控制逻辑、闭环控制、群控

### Secondary（1.5 分/项）—— 具备实操，支撑但要谨慎表述

> 与数据中心方向相比，Secondary 增加「冷水机组、螺杆机、离心机、冷却塔、板换、锅炉」——这些在某商业综合体实习中直接接触过，属真实可讲的设备级经验。

### Weak（登记不扣分，触发风险提示）—— 知识性了解，无工程交付经历

> 命中 Weak 项时：不扣分，但必须在解析卡「命中 Weak」登记，并在结论中给出诚实桥梁话术建议——只能指向真实可迁移能力，不得生成听起来像经历的表述。

## 二、方向契合锚点表（30 分）

锚定「冷却系统与热管理」主线。按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 空调制冷系统研发 / 设计 | 25–30 | 主线岗位，直接对口 |
| 暖通设计 / 暖通工程 | 22–28 | 高度相关 |
| 建筑节能与咨询 | 18–24 | 相关，项目二可直接支撑 |
| 设备厂商技术支持 / 应用工程师 | 15–22 | 相关但偏支持，需确认成长性 |
| 数据中心冷却 | 12–18 | 属另一方向的强项，此配置下分数偏低 |
| 非暖通方向 | 0–8 | 基本不匹配 |

判定提示：岗位名称与职责不一致时，以职责为准并在解析卡说明判断依据。若 JD 实质是数据中心冷却，应改用 `direction_datacenter.md` 而非在本配置下打低分。
