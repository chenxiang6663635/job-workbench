### 探针 B · P2 错根写（同名工作区）

要造「应用根与数据根**各有一个 `personal`**、内容不同」的局面：

```powershell

$env:JOBWS_DATA_DIR = Join-Path $probe "data"
New-Item -ItemType Directory -Force -Path $env:JOBWS_DATA_DIR | Out-Null
python tools\jobws.py init
# `track add` 的必填项是 --company / --role / --direction / --batch（没有 --status，阶段是 --stage）
# 方向 id 取决于装入的领域插件；可用 Get-ChildItem template\profiles\*\directions 查看
python tools\jobws.py track add --company "PROBE_DATA_ROOT" --role "probe" `
    --direction backend --batch 正式批
# 2) 启动应用（沿用上面同一个 JOBWS_DATA_DIR），然后：
try { (Invoke-WebRequest "http://127.0.0.1:8765/api/applications?ws=personal" -UseBasicParsing).Content } catch { $_.ErrorDetails.Message }
```

**判据**：返回里**有** `PROBE_DATA_ROOT`、**没有**应用根 demo 的 A_ONLY 记录；
且请求前后**应用根那份台账未被改写**——比对
`<应用根>\personal\05_投递追踪\tracker.csv` 的 `Get-FileHash`（台账真实路径已实跑确认：
`personal\05_投递追踪\tracker.csv`，不是 `personal\tracker\`）。

若返回应用根那份数据 → 静默错根，属**阻断**，立即停并报告。
