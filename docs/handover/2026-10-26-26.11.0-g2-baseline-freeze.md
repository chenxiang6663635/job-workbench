## 三、重建触发规则（本文件的核心用途）

| 变化位置 | 需重建 B 组？ | 说明 |
|---|---|---|
| **A 类**任意文件 | **是** | 载荷变了，制品必变 |
| **B 类**任意文件 / 工具链版本 | **是**（或至少重新评估） | 生成方式变了 |
| **C 类** `release.yml` 仅 Publish 阶段 | **否** | A+ 已于 2026-10-26 合并（#407，`80f92f5`），**实证不触发重建** |
| **C 类** `release.yml` 的 package job / 构建参数 | **是** | 升级为 B 类 |
| **C 类** `tests/**` | **否** | 影响验收判定，不影响 EXE 字节 |
| `skills/**`、`integrations/dsh/**` | **否** | 当前 Desktop 打包链未纳入（**PR #371 已于 2026-10-26 合并（`5971163`），实证不触发重建**） |
| `docs/**` | **否** | 纯治理 |
| `package.json > version` | **是**（当 G4 落章时） | 改变制品版本元数据 |

**推论**：A+ 与 PR #371 **都不触发** B 组失效，因此**在冻结后即可启动重建，不必等它们合并**。
