## 本版经验（已转化为制度或待办）

1. **artifact 自带 sha256 digest**：下载验收可直接对照 GitHub API 的 `digest` 字段——本版四重校验（zip digest → 解压六件 → exe sha256 → exe sha512 对照 `latest.yml`）即为后续版本的模板。
2. **SBOM 进链**：`release.yml` 固化，零包即 throw；`installer` artifact 内即含 `sbom.spdx.json`，Release 资产从四样变五样。
3. **发布同源纪律的执行形态**：tag 前冻结全部 PR（本版 docs/UI 小批均挂到 tag 之后），tag 用 `git tag -a <tag> <commit>` 显式钉提交而非 HEAD——即使有意外合入也不破坏同源性。
4. **DSH 接入件的 headless 边界**（待办：补进 `integrations/dsh/README.md` 已知边界）：preset 在 headless 下 pending 不生效，属宿主运行时形态，非本仓缺陷。
