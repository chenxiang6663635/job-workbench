# 项目官网设计（docs site）

- 日期：2026-09-28 · 状态：定稿（用户已审定；下载节按「全免费」方案修订）
- 实施时建分支 `docs/site`（本文件随实施 PR 提交）

## 背景与目标

「使用手册」现挂在 GitHub 上——目标受众（无代理/国内网络）打不开，也无法作项目门面。
目标：一个国内可访问的项目站（介绍 + 使用手册 + FAQ + 下载），形态参照 Clash Verge
文档站（MkDocs Material）。受众：国内求职者（中文为主）。

## 非目标

- 不做营销落地页、不做博客、不做多版本文档、不放源码/内部文档、站上无遥测无统计。

## 内容地图（一期）

| 页面 | 来源 | 说明 |
|---|---|---|
| 首页 | 新写（README 改编） | 定位 + 特性 + 8 页截图 + 下载 CTA + **Referral 段** |
| 使用手册 | `docs/usage-guide.zh-CN.md`（组装） | 英文版 = `docs/usage-guide.md`；FAQ 留在手册内不拆 |
| 下载 | 新写 | 见「下载设计」 |
| 数据与隐私 | `docs/data-flow-matrix.md`（组装） | 隐私权威底稿 |
| 支持与兼容 | `docs/support-and-compatibility.md`（组装） | 含诚实状态 |

- 组装**白名单**（物理排除 `.codebuddy/`、`personal/`、内部文档）
- i18n：默认中文；英文一期 = 首页 + 手册（素材现成：usage-guide.md 英文版 + 英文截图），
  缺英文的页回退中文

## 技术架构

```
GitHub Actions（构建在自家手里，绕开 EdgeOne 构建环境未知）：
  site/scripts/build_site.py 组装（docs/ 为唯一真源）→ mkdocs build --strict
  → 产物推 site-dist 分支
EdgeOne Makers（零构建分发）：监控 site-dist → 默认域名访问
备选：CI 内 EdgeOne CLI 上传（token 进 Secrets）
```

- 单源原则：文档真源在 `docs/`，站点构建时组装——不存在两处维护
- 仓库新增：`site/`（mkdocs.yml + content/ 新写页 + scripts + pin 的 requirements）+
  `.github/workflows/site.yml`；不碰产品代码
- 实施第一步 = **链路验证**（hello 页跑通「构建→分发→域名打开」再堆内容）

## 下载设计（全免费，零自费）

- 主通道：**GitHub Releases**（资产上限 2GB，包 122.74MB ✓）+ SHA256SUMS 校验和
- 备用通道：**免费网盘兜底链接**（发版时顺手传一份；选型实施时定）+ 如实文案
  「国内网络访问 GitHub 不畅时可用备用链接，或联系我们获取」
- 页面元素：版本号 + 发布日期（构建时从 `web/electron/package.json` / CHANGELOG 注入）、
  文件大小、SHA256、「安装包未签名（SmartScreen 提示）」说明
- 成本：**0 元**（全部免费通道；用户明确「个人项目不自费」）
- **核实记录（2026-09-28）**：包 122.74MB；Gitee 发行版单附件 ≤100MB、蓝奏云 100MB 线、
  123 云盘免登录线 100MB——均装不下或需登录；**EdgeOne 免费套餐官方禁止大文件分发**
  ——站点只跑网页内容（合规），安装包不上站点；付费通道（COS 等）因不自费决策排除
- **将来**：出现「大量外部下载」需求时再评估（含「花小钱 + 费用总封顶」形态），现在不花钱

## 边界与安全

- 组装白名单 = 隐私边界；站上零遥测（与项目立场一致）
- `site.yml` 独立（`paths: docs/**, site/**`）；PR 上 `build --strict` 必需，
  main push 构建 + 推产物分支
- `site/` 纳入 `lint size` 纪律
- 站点内容 = 已审计的公开文档（2026-09-26 全仓扫描结论适用）

## 测试与验证

- CI：`mkdocs build --strict`（坏链即红）；本地：组装 + `mkdocs serve` 预览
- 上线实测：默认域名发 1-2 个无代理受众 → 可达性结论 → 决定是否走 C（域名 + 备案）
- 下载实测：GitHub 链接与备用网盘链接均可用 + SHA256 核对

## 需用户动作（实施前）

1. 注册 EdgeOne 国际版（邮箱，免信用卡）+ 授权 GitHub 仓库
2. （上线后）拿默认域名发 1-2 个无代理受众实测

## 实施偏差（记录）

实施后补记——与设计稿之间的两处有意差异，防止后续审计当成缺陷重新发现：

1. **首页截图取 4 张代表页**（有意精简；8 张全量在 README）：设计稿列 8 页截图，
   首页只放看板 / 追踪表 / 简历工坊 / 进展四张。
2. **下载页未含「文件大小」元素**（无注入源、硬编码会漂移）：构建链只注入版本号
   与发布日期；安装包大小随发版变化，写死会失准，本批不做。
