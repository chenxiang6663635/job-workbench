# 生成或定制领域插件（人确认制）

适用场景：工作台内置的领域插件与你的专业不匹配（小众专业、交叉方向），
或你要按自己的真实经历校准词典与方向锚点。**产物只写你的工作区 `config/`——
不碰内置插件、不进仓库版本控制。**

## 硬规则（四条，不可协商）

1. **禁止编造**：词典候选词必须对应你真实做过的事。每个候选词附一个自检问题
   （「这件事能不能经得起两层追问？」），答案存疑 → 降层或删，不许「大概会」。
2. **逐层确认**：Primary / Secondary / Weak 逐条过，你明确「保留 / 降层 / 删」
   之后才算数；**不许 AI 自行定层后直接写盘**。
3. **锚点逐档确认**：方向锚点表的岗位类型与分值区间由你认可——AI 只提建议区间，
   每档都要你点头。
4. **写盘前必过校验**：`jobws lint domains` 通过（见第 4 步）才落盘，不通过不写。

`failure_keywords.txt` 是唯一例外：初始给通用骨架（流程性分类，不含能力主张），
明确标注「随实战校准」即可。

## 流程

### 1. 判断路径：定制现有，还是新建插件

- **定制现有**：工作区 `config/` 已有内置插件四件套（`profile.md` / `lexicon.md` /
  `failure_keywords.txt` / `directions/`）→ 只需校准词典分层、锚点档位、关键词；
- **新建插件**：内置插件里没有你的专业 → 生成全套四件套，走候选目录流程。

先读工作区 `AGENTS.md`（专业、经历、目标岗位）——采集的一半答案在那里。

### 2. 采集事实（只问，不猜）

依次问清三件事：

1. **岗位群**：你实际会投的 3–8 类岗位（招聘网站上你会搜的词）；
2. **真实经历**：做过的项目、课程、工具、交付物（也可以从档案提取候选让你逐条勾）；
3. **方向划分**：1–3 个（每个方向 = 一类岗位 + 特有词 + 锚点档）。

AI 只处理你列出的经历与档案里已有的事实，**不补「应该会」的词**。

### 3. 生成候选（全部标【待确认】）

产物格式与示例见 `references/plugin-templates.md`：

| 产物 | 内容 | 你的确认动作 |
|---|---|---|
| `profile.md` | 身份表（ID / 名称 / 适用人群 / 覆盖岗位 / 内置方向 / 建立日期） | 通读一遍 |
| `lexicon.md` | 三级词典（每词附自检问题） | 逐层逐条：保留 / 降层 / 删 |
| `directions/<方向>.md` | 方向补充词 + 锚点表 | 锚点逐档：岗位类型与分值区间 |
| `failure_keywords.txt` | 「类别=关键词」通用骨架 | 知悉「随实战校准」 |

### 4. 落盘

**定制现有**：先把 `config/` 下的原文件复制到 `config-archive-<日期>/`（可回退），
再按确认结果就地修改。

**新建插件**：

1. 生成到 `<工作区>/config-candidate/<domain-id>/`（目录名 = 小写字母 / 数字 /
   连字符，与 `profile.md` 的「插件 ID」一致）；
2. 校验：`jobws lint domains --root <工作区>/config-candidate`——必须看到
   「0 个不合规」；
3. 归档：`config/` 里已有的四件套先移到 `config-archive-<日期>/`（为空则跳过）；
   **运行文件（`imap.json` 等）不动**；
4. 平铺：把候选目录里的四件套直接放进 `config/`（平铺，不加一层目录）。

### 5. 收尾

- 摘要：生成了什么、改了哪些文件、归档在哪；
- 实测：拿一条真实 JD 评分，确认词典与锚点被读到（方向契合维度按新表出分）；
- 提醒：分层写错的代价（面试露馅）远大于漏写——实战里继续校准，随时回来再跑一遍。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| AI 凭常识补词典词条 | 面试被追问露馅 | 每词配自检问题，存疑降层或删 |
| 跳过逐层确认直接写盘 | 词典失真且你不自知 | 逐层逐条过，点头才算数 |
| 让 AI 直接定锚点分值 | 分数与你自我认知脱节 | AI 只提区间，逐档确认 |
| 新建时不归档旧四件套 | 新旧文件混合、评分来源不清 | 平铺前先归档 |
| 跳过 lint domains | 缺层 / 格式错会静默失效 | 写盘前必过校验 |
