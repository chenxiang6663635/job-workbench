# 证据标签与差距清单（细节）

主文件只留纪律，两处细则放这里按需读取。

## 评分证据标签

技术匹配每一条命中，都要在词条后追加【精确/模糊/语义】判定依据标签，说明这条匹配
是怎么判出来的：

- **精确**：JD 原文直接出现该词条或其同义词。
- **模糊**：JD 措辞与词条相近但不完全一致（如「数据挖掘」vs「数据分析」）。
- **语义**：JD 表述与词条语义等价但措辞完全不同（如「节能控制算法开发」vs 词典「控制逻辑」）。

写法示例：`- **控制 / 群控（3）【语义】**：JD"节能控制算法开发"语义等价`。

旧卡无标签也能读，但新卡一律带标签——前端「评分证据可追溯」下钻正是靠它区分
「词面命中」与「语义推断」，也让人一眼看出哪些分是推断来的。

## JD↔简历差距清单（命令与输出）

```
jobws jd --gap --resume <版本> "<工作区>/01_岗位池/<公司>_<岗位>/解析卡.md" --workspace <工作区>
```

输出三分：

- **已覆盖（matched）**：JD 要求的词典词，当前简历版本里能直接证明
- **可召回（injectable）**：母版（`简历_主版_v1.0.md` + `00_事实库/`）里有、这一版没用上
- **真实缺口（missing）**：简历与母版都没有

对用户的建话术建议：injectable 可以放心召回（既有事实，换一种表述而已），
missing 只能靠补真实经历——**不得靠改词硬凑**。Web 端岗位详情页有同样的差距面板。
