# 评分表：四维度、稳定性分档与阈值

主文件（SKILL.md）只保留纪律，表格放这里按需读取。

## 四维度

| 维度 | 分值 | 判据 |
|---|---:|---|
| 技术匹配 | 30 | 按插件词典比对。Primary 3 分/项，Secondary 1.5 分/项；Weak 登记不扣分但触发风险提示 |
| 经历匹配 | 25 | 逐条比对用户的经验资产与 JD 职责。对上核心职责 8–10 分，侧面支撑 3–5 分，无关 0 分。**必须回查 `00_事实库/`** |
| 方向契合 | 30 | 按插件的方向锚点表取值 |
| 培养与稳定性 | 15 | 见下表 |

## 培养与稳定性（15）

| 分值 | 判据 |
|---|---|
| 13–15 | 明确校招培养体系（导师制 / 轮岗 / 培训），岗位为技术核心岗，无强制长期驻场或倒班 |
| 9–12 | 校招岗但培养体系未明示，岗位偏技术，工作地可接受 |
| 5–8 | 培养信息缺失；岗位偏运维或现场执行；或需长期出差 |
| 0–4 | 劳务派遣 / 外包、非技术岗、强制倒班或驻场不可接受 |

本维度取代常见的「文化契合」。校招 JD 里的文化表述多为套话，从文本判断可靠度低；而是否有培养体系、是否核心岗、工作形态是否可持续，既可从文本判断，也对决策影响更大。

## 阈值与动作

| 总分 | 档位 | 动作 |
|---|---|---|
| 75–100 | 强烈建议投 | 立即生成投递包 |
| 60–74 | 建议投 | 生成投递包 |
| 45–59 | 斟酌 | 先看缺口能否一周内补 |
| 30–44 | 大概率跳过 | 除非有内推或岗位调整等额外信息 |
| 0–29 | 不投 | 终止 |
