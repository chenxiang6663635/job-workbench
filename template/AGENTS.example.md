## 六、简历版本

| 用途 | 文件 | 说明 |
|---|---|---|
| 事实母版 | `02_简历工坊/简历_主版.md` | 不投递，含内部备注与贡献边界 |
| 方向 A | `02_简历工坊/简历_<方向A>.md` | 投递版 |
| 方向 B | `02_简历工坊/简历_<方向B>.md` | 投递版 |

多版本 = 1 母版 + N 派生，**只改四处**：求职方向、Profile、技能顺序、项目表述。项目事实不变。

PDF 生成源是 `02_简历工坊/pdf/resume_*.html`，不是 Markdown。改简历内容必须同步更新 HTML。

照片：覆盖 `02_简历工坊/pdf/photo.jpg`。不需要照片时删除 HTML 中的 `<img class="photo" ...>` 一行。
