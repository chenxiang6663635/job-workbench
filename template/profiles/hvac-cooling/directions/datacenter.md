# 方向：数据中心冷却 / 热管理

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

---

## 一、方向特有补充词

在共用词典之外，本方向额外计分：

### Secondary 补充

PUE、CLF、WUE、冷却能耗链
CRAH、CRAC、机房空调、送回风温度、冷热通道
部分负荷、台数控制、设定值优化、自然冷却、Free Cooling
容量匹配、IT 负荷、机柜功率密度

### Weak 补充（本方向尤其容易被追问）

液冷覆盖率、冷板与浸没式的选型取舍
数据中心运维实操、故障处置、应急演练

## 二、方向契合锚点表（30 分）

按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 数据中心冷却 / 热管理 | 25–30 | 主线岗位，直接对口 |
| IDC 基础设施 / 机房暖通 | 22–28 | 高度相关，需确认是否偏运维 |
| 液冷产品研发 / 热设计 | 20–26 | 相关，但 Weak 项大概率被追问 |
| 储能热管理 / 电池热管理 | 18–24 | 热管理能力可迁移 |
| 建筑能源管理 / 节能优化 | 12–18 | 部分相关 |
| 非热方向 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。
