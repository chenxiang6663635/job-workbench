# 方向：储能 / 电池热管理

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

> 词条以**传热与系统侧**为主（液冷 / 风冷 / 均温 / 热阻可从暖通制冷迁移）；电池化学、电芯工艺类词条不在共用词典内，锚点给分时需说明依据，避免把不拥有的能力算成分数。

---

## 一、方向特有补充词

在共用词典之外，本方向额外计分：

### Secondary 补充

电池热管理、PACK 热管理、液冷板、风冷通道
液冷与风冷对比、温差控制、均温性、最高温升
热失控、热失控边界、热蔓延、防爆阀、消防联动
产热功率、发热量估算、充放电倍率、循环工况
储能集装箱、液冷机组、管路设计

### Weak 补充（本方向尤其容易被追问）

电芯选型、BMS 策略、浸没式冷却
热失控触发实验、针刺 / 过充测试

## 二、方向契合锚点表（30 分）

按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 电池热管理 / 储能热设计 | 25–30 | 主线岗位，直接对口 |
| PACK / 系统级热管理 | 22–28 | 高度相关 |
| 热失控防护 / 安全设计 | 20–26 | 相关；传热侧可支撑，电化学侧需确认 |
| 液冷系统研发（非储能场景） | 18–24 | 可迁移（另有 `thermal-management`） |
| 暖通 / 制冷系统研发 | 12–18 | 部分相关（另有 `hvac`） |
| 非储能非热方向 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。
