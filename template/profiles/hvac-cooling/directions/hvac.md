# 方向：空调制冷 / HVAC 优化

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

---

## 一、方向特有补充词

在共用词典之外，本方向额外计分：

### Secondary 补充

负荷计算、逐时负荷、室内设计参数
全空气系统、风机盘管、新风系统、气流组织
水系统定压、膨胀水箱、补水、排气
供热、锅炉房、换热站、热力入口
节能改造、能耗审计、运行调适

### Weak 补充

洁净空调、医院洁净手术室、GMP
BA 系统实施、楼宇自控调试

> 相比数据中心方向，本方向的 Secondary 更偏**设备级与系统级**（冷水机组、螺杆机、离心机、冷却塔、板换、锅炉已列入共用词典）——这些在现场实践中直接接触过，属真实可讲的经验。

## 二、方向契合锚点表（30 分）

按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 空调制冷系统研发 / 设计 | 25–30 | 主线岗位，直接对口 |
| 暖通设计 / 暖通工程 | 22–28 | 高度相关 |
| 建筑节能与咨询 | 18–24 | 相关，能耗类项目可直接支撑 |
| 设备厂商技术支持 / 应用工程师 | 15–22 | 相关但偏支持，需确认成长性 |
| 数据中心冷却 | 12–18 | 属另一方向的强项，此配置下分数偏低 |
| 非暖通方向 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。

若 JD 实质是数据中心冷却，应改用 `datacenter` 方向配置，而不是在本配置下打低分。
