# 方向：热设计 / CAE

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

---

## 一、方向特有补充词

在共用词典之外，本方向额外计分：

### Secondary 补充

热设计、散热设计、散热结构、翅片设计、风道设计
结构-热耦合、热应力、多物理场耦合
可靠性、寿命评估、加速老化、温度循环
仿真-实验对标、模型校准、测温实验、热电偶、数据采集
Ansys、Icepak、FloTHERM、热仿真报告

### Weak 补充（本方向尤其容易被追问）

DOE 实验设计、公差与量产一致性
EMC / 结构堆叠协同设计

## 二、方向契合锚点表（30 分）

按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 热设计工程师（电子 / 结构散热） | 25–30 | 主线岗位，直接对口 |
| 热仿真 / CAE 分析工程师 | 22–28 | 高度相关（另有 `thermal-fluid-cfd`） |
| 冷板 / 液冷部件研发 | 20–26 | 相关，流体与传热能力可支撑 |
| 结构-热-可靠性多物理场岗位 | 20–26 | 相关 |
| 暖通 / 制冷系统研发 | 12–18 | 部分相关（另有 `hvac`） |
| 非热方向 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。
