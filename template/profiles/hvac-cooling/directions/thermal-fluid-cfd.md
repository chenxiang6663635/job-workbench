# 方向：热流体仿真 / CFD

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

---

## 一、方向特有补充词

在共用词典之外，本方向额外计分：

### Secondary 补充

CFD、湍流模型、k-epsilon、k-omega SST、雷诺时均
边界条件设置、网格无关性验证、网格划分、近壁面处理
温度场、速度场、湿度场、CO₂ 浓度场、气流组织仿真
Fluent、STAR-CCM+、OpenFOAM、共轭传热、CHT
模型降阶、代理模型、参数化扫描、批量工况

### Weak 补充（本方向尤其容易被追问）

LES 大涡模拟、瞬态仿真调参
自编求解器、数值格式开发

## 二、方向契合锚点表（30 分）

按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| CFD 仿真工程师（热 / 流体） | 25–30 | 主线岗位，直接对口 |
| 热仿真 / 热设计（含 CAE） | 22–28 | 高度相关（另有 `thermal-design-cae`） |
| 系统节能与运行优化仿真 | 18–24 | 相关，EnergyPlus / 系统仿真项目可直接支撑 |
| 暖通 / 制冷系统研发 | 15–22 | 相关（另有 `hvac`） |
| 数据类岗位（非 CFD 但要建模能力） | 10–16 | Python / 建模能力可迁移 |
| 非仿真且非热方向 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。
