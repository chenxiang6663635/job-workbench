# 方向：热管理（电子设备 / 服务器 / 芯片散热）

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

---

## 一、方向特有补充词

在共用词典之外，本方向额外计分：

### Secondary 补充

电子设备热管理、芯片散热、服务器散热
冷板、冷板液冷、CDU、Manifold、快接头
热界面材料、TIM、导热垫、导热硅脂、均温板、VC、热管
热阻网络、热阻拆解、结温、Tj、功耗密度
风冷散热、散热器选型、风扇曲线、噪音约束

### Weak 补充（本方向尤其容易被追问）

芯片级封装散热、真空腔均热板量产工艺
整机散热实测、风洞测试、红外热像

## 二、方向契合锚点表（30 分）

按岗位名称与职责取最接近的一档，同档内按 JD 契合程度微调。

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 热管理工程师（电子设备 / 服务器 / 芯片散热） | 25–30 | 主线岗位，直接对口 |
| 冷板液冷 / CDU 系统研发 | 22–28 | 高度相关，流体侧能力可直接支撑 |
| 数据中心冷却 / IDC 暖通 | 20–26 | 相关，属另一方向的强项（可参考 `datacenter`） |
| 电池 / 储能热管理 | 18–24 | 热管理能力可迁移（另有 `energy-storage-thermal`） |
| 暖通空调系统研发 / 设计 | 12–18 | 部分相关（另有 `hvac`） |
| 非热方向 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。
