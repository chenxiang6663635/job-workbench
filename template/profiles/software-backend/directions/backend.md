# 方向：后端开发

评分共用一套权重（技术匹配 30 / 经历匹配 25 / 方向契合 30 / 培养与稳定性 15），本文件只定义**方向特有补充词**与**方向契合锚点表**。

共用词典见 `../lexicon.md`。

---

## 一、方向特有补充词

### Secondary 补充

分布式、一致性、CAP、分布式事务、幂等
网关、负载均衡、限流、熔断、降级
ORM、连接池、分库分表、读写分离
性能调优、压测、Profiling、链路追踪
OAuth、JWT、会话管理、权限模型

### Weak 补充

亿级流量架构实战、异地多活
Service Mesh、Istio 生产落地
自研中间件、存储引擎开发

## 二、方向契合锚点表（30 分）

| 岗位类型 | 分值 | 说明 |
|---|---:|---|
| 后端开发 / 服务端开发 | 25–30 | 主线岗位，直接对口 |
| 平台工程 / 基础架构 | 22–28 | 高度相关，通常要求更深的系统功底 |
| 全栈开发 | 20–26 | 相关，需确认后端占比 |
| 数据工程 / 大数据开发 | 18–24 | 部分能力可迁移 |
| 测试开发 / 运维开发 | 15–22 | 相关但偏离主线 |
| 算法工程 / 机器学习工程 | 10–16 | 偏研究，后端成分较少 |
| 非技术岗 | 0–8 | 基本不匹配 |

岗位名称与职责不一致时，**以职责为准**并在解析卡说明判断依据。
