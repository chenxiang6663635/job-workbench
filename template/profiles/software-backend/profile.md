# 领域插件：软件后端与数据工程

| 项 | 值 |
|---|---|
| 插件 ID | `software-backend` |
| 名称 | 软件后端与数据工程 |
| 适用人群 | 计算机、软件工程、数据科学及相关专业的应届生与社招候选人 |
| 覆盖岗位 | 后端开发、服务端开发、数据工程、大数据开发、平台工程 |
| 内置方向 | `backend`（后端开发）、`data`（数据工程） |
| 建立日期 | 2026-08-30 |

## 结构

```
software-backend/
├── profile.md        本文件：插件元信息
├── lexicon.md        三级词典，两个方向共用
└── directions/
    ├── backend.md    方向锚点表 + 方向特有词
    └── data.md
```

## 如何新增方向

在 `directions/` 下新建 `<direction-id>.md`，内容只需包含**该方向特有的补充词**与**方向锚点表**。

## 如何新增领域

在 `template/profiles/` 下新建 `<domain-id>/`，按同样三件套组织，无需改动任何 Python 代码。
