# 知识库

本层放**知识**：概念、原理、速查卡、专题整理。

## 最重要的约定：不要从这里开始

日常训练从 `../03_面试准备/` 开始。只有**说错了、被追问超出现有表达时**，才回来翻这里。

理由：知识是补不完的，从知识库开始容易陷进去一天，产出的是一堆笔记而不是能说出口的答案。而面试考的是表达。

正确的触发时机是：模拟面试中被问住 → 记下漏洞 → 回来定点查 → 补成一段能说的表达 → 回填事实卡或表达材料。

**"说错"是有效的学习信号，顺着它补的知识记得最牢。**

## 放什么

- 说不清的原理，查完整理成自己的话
- 常被追问的技术点，整理成速查卡
- 某个专题的系统梳理
- 面试后被问住、当场没答上来的内容（**这类最高优先级**）

## 不放什么

- 从没被问过、只是"觉得该学"的内容 —— 会无限膨胀
- 教程原文或文档复制 —— 记不住，也不会回头看
- 与求职方向无关的知识 —— 占用检索注意力

## 组织建议

按你所在领域的技术主题分子目录即可。每个主题下建议分两类：

| 类型 | 用途 | 篇幅 |
|---|---|---|
| 速记 | 系统理解，从头到尾能讲 | 较长，一次读通 |
| 速查卡 | 面试前快速过一遍 | 一页以内，只看要点 |

同一主题同时有速记和速查卡是正常的——前者用来学，后者用来复习。

## 命名

`主题_类型_v0.1.md`，类型用「面试速记」或「速查卡」。例：`制冷循环与COP速查卡_v0.1.md`、`数据结构面试速记_v0.1.md`。

## 与面试准备的分工

| | 03_面试准备 | 04_知识库 |
|---|---|---|
| 放什么 | 表达（能说出口的成稿） | 知识（概念与原理） |
| 什么时候用 | 每天 | 被问住之后 |
| 产出标准 | 能脱稿说出来 | 能讲清原理 |
