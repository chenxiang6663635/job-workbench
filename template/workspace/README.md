# 工作区骨架

本目录是空的工作区骨架。运行 `python tools/init_workspace.py` 会把本目录复制到你的工作区，然后你在那里填自己的内容。

## 六个模块

| 模块 | 放什么 | 入口文件 |
|---|---|---|
| `00_事实库/` | 项目事实卡——**唯一事实源，先填这里** | `_模板_事实卡.md` |
| `01_岗位池/` | 每个岗位一个目录：JD 原文 + 解析卡 | `_模板_解析卡.md` |
| `02_简历工坊/` | 简历 md + HTML 模板 + 生成的 PDF | `pdf/_模板_resume.html` |
| `03_面试准备/` | 自我介绍、项目表达、题库、行为面、技术面、复盘 | `README.md` |
| `04_知识库/` | 知识词典与速查卡，按需查阅 | `README.md` |
| `05_投递追踪/` | 追踪表 + 每次投递归档 | `README.md`、`_示例_tracker.csv` |

以 `_模板_` 开头的文件是待复制填写的样板；`_示例_` 开头的是仅供查看的参考数据，可删除。

## 建议的填写顺序

**一、先建事实库。** 这是唯一事实源，简历动词、行为故事、JD 评分的「经历匹配」维度都要回查它。没有它，后面所有环节都只能凭印象——写出来的动词经不起追问，评分也只是猜测。

**二、写简历，生成 PDF。** 从 `pdf/_模板_resume.html` 复制出 `resume_<版本>.html`。注意 PDF 的生成源是 HTML 不是 Markdown。

**三、解析 JD，开始投递。** 有 JD 就建岗目录、存原文、填解析卡、走完整流程。

**四、面试准备按需补。** 先写自我介绍和项目口述，被问住的地方记下来，回知识库定点补。

## 各模块要点

### 00_事实库 —— 唯一事实源

每张事实卡写清四件事：做了什么、**你的贡献边界**、可验证证据、**不能越界的说法**。

后两项最容易被忽略，也最关键——它们直接决定简历里哪些动词能用、面试里哪些话不能说。

### 03_面试准备 —— 先表达，后补知识

不要从学知识开始。先压缩成 30–90 秒能说的答案，被追问、暴露漏洞，再回来定点补知识。

说错了才是有效的学习信号。

### 04_知识库 —— 被问住之后才来

日常训练不从这里开始。只有说错了、被追问超出现有表达时，才回来翻。

### 05_投递追踪 —— 归档是对抗遗忘的办法

JD 会改、简历会迭代、记忆会模糊。每次投递存下 JD 快照与当次简历，三个月后才能回答"我投这家时用的是哪版"。

## 关于 99_归档

历史文件与不再维护的脚本放这里，只增不改。历史文档中的旧目录名不做改写——如实记录当时状态才是它的价值。
