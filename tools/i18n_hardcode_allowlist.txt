# 界面硬编码中文检查的允许清单（`tools/check_i18n_hardcode.py` 读它）。
#
# 只登记**领域数据**：阶段/批次/轮次/方向枚举、CSV 列名、接口中文字段名、
# 工作区里的真实文件/目录名。它们的字面量同时也是 tools/tracker.py 与工作区
# 文件里的取值——翻译了就与历史数据和 CLI 对不上（见 B12 计划的判定原则）。
#
# 不登记：UI 文案（按钮/label/placeholder/空态/错误态/列头/标题）。那类必须走 t()，
# 语言包在 web/frontend/src/i18n/locales/。
#
# 格式：一行一个文件，`=` 后面是**放行的片段**（用 | 分隔），行尾 `#` 是理由。
#   components/Foo.tsx = 已挂|已投      # 阶段枚举
#
# 为什么不整文件放行：本清单最初是文件级的，结果一个"已豁免"的文件里藏着 4 处
# 漏翻（列头、差异标签、按钮 tooltip），而检查全绿。改成片段级之后，往同一个
# 文件里再加一句硬编码中文必然报错。
#
# 清单是"现状存档"：某句中文翻掉了、文件删了或改名了，这里必须同步删——
# 脚本会报「片段已不再出现」「文件已无命中」两类清单问题，避免给将来的同名
# 中文预授权。生成草稿：`python tools/check_i18n_hardcode.py --print-allowlist`。
